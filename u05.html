Sections 5.1 and 5.2: Increasing and decreasing functions, relative extrema

The big idea

This section uses the derivative to find where a graph goes up, where it goes down, and where it turns around. Where \(f'\) is positive the graph rises, and where \(f'\) is negative the graph falls. The one thing to remember: build a sign chart for \(f'\) (never for \(f\)), because the hills and valleys of the graph can only sit at numbers where \(f'\) is zero or does not exist.

Intervals, and why the answers use open intervals

An interval is an unbroken piece of the number line. The open interval \((a, b)\) is the set of all \(x\) with \(a \lt x \lt b\); the endpoints are left out. The closed interval \([a, b]\) includes both endpoints. An interval can run forever in one direction, as in \((a, \infty)\) or \((-\infty, b)\), and the whole number line is \((-\infty, \infty)\). The symbol \(\infty\) is never a number, so it always gets a round bracket.

In this unit every answer about where a function increases or decreases is written with open intervals, the way the textbook does it. The reason is that at a turning point the function is neither going up nor going down, so the turning point itself does not belong to either interval.

What increasing and decreasing mean

Definition (increasing and decreasing)

A function \(f\) is increasing on an interval if \(f(x_1) \lt f(x_2)\) for any \(x_1 \lt x_2\) in the interval. The graph rises from left to right.

A function \(f\) is decreasing on an interval if \(f(x_1) \gt f(x_2)\) for any \(x_1 \lt x_2\) in the interval. The graph falls from left to right.

In plain words: increasing means that as you move to the right, the values of the function go up. Decreasing means that as you move to the right, the values go down.

Always read a graph from left to right, the same direction \(x\) grows. A graph that goes up as you move to the right is increasing there, no matter how high or low it sits on the page. Being above or below the \(x\)-axis has nothing to do with increasing or decreasing: a function can be negative and increasing at the same time.

Why the sign of f' tells you the direction

Recall that \(f'(c)\) is the slope of the tangent line to the graph of \(f\) at the point \((c, f(c))\). If the tangent line has positive slope, the graph is climbing at that point. If the tangent line has negative slope, the graph is going down at that point. So if \(f'(x) \gt 0\) at every point of an interval, the graph is climbing everywhere on that interval, and \(f\) is increasing there.

The professor proves this with the Mean Value Theorem, which is stated in full near the end of this lesson. Take any \(x_1 \lt x_2\) in an interval where \(f'(x) \gt 0\). The Mean Value Theorem gives a number \(c\) between them with

\[f(x_2) - f(x_1) = f'(c)\,(x_2 - x_1).\]

Both factors on the right are positive (\(f'(c) \gt 0\) and \(x_2 - x_1 \gt 0\)), so \(f(x_2) - f(x_1) \gt 0\), which means \(f(x_1) \lt f(x_2)\). That is exactly the definition of increasing. The same argument with \(f'(c) \lt 0\) shows \(f\) is decreasing.

Test for increasing and decreasing functions

Suppose \(f\) is differentiable (has a derivative) at every point of an open interval \(I\).

  • If \(f'(x) \gt 0\) for all \(x\) in \(I\), then \(f\) is increasing on \(I\).
  • If \(f'(x) \lt 0\) for all \(x\) in \(I\), then \(f\) is decreasing on \(I\).
  • If \(f'(x) = 0\) for all \(x\) in \(I\), then \(f\) is constant on \(I\).

In plain words: a positive derivative means the graph is going uphill, and a negative derivative means it is going downhill. A derivative that is zero all along an interval means the graph is flat there.

Where f' can change sign, and test points

The professor's lecture states a useful fact about continuous functions. (A function is continuous on an interval when its graph there has no breaks, holes, or jumps.) If a function is continuous on an interval and has no zeros on a piece of that interval, then it has one sign on the whole piece: all positive or all negative. The reason is the Intermediate Value Theorem, which says a continuous function cannot get from one value to another without passing through every value in between. So to go from positive to negative, the function would have to pass through 0. So once you know where a function is 0, you can find its sign on each piece between zeros by plugging in a single number from that piece. That number is called a test point or test value.

Apply this to \(f'\). The sign of \(f'\) can only change at a number where \(f'(x) = 0\), where \(f'(x)\) does not exist, or where \(f\) itself is not defined (for example at a vertical asymptote). These numbers cut the number line into open intervals, and on each one \(f'\) has a single sign.

Critical numbers

Definition (critical number)

A critical number of \(f\) is a number \(c\) in the domain of \(f\) such that either \(f'(c) = 0\) or \(f'(c)\) does not exist. The point \((c, f(c))\) is called a critical point.

In plain words: a critical number is an \(x\)-value where the function exists and its graph either has a flat tangent line or has no slope at all (a sharp corner, a cusp, or a vertical tangent). A critical number is an \(x\)-value only; the critical point is the dot on the graph above it.

The phrase "in the domain" matters. Three quick examples show the cases.

  • For \(f(x) = x^2\), \(f'(x) = 2x\), which is 0 at \(x = 0\). So 0 is a critical number of the first kind (\(f' = 0\)).
  • For \(f(x) = x^{1/3}\), the power rule gives \(f'(x) = \tfrac{1}{3}x^{-2/3} = \dfrac{1}{3x^{2/3}}\). This does not exist at \(x = 0\) because of division by 0, but \(f(0) = 0\) is defined. So 0 is a critical number of the second kind (\(f'\) does not exist). The graph has a vertical tangent line there.
  • For \(f(x) = \dfrac{1}{x}\), \(f'(x) = -\dfrac{1}{x^2}\) also does not exist at \(x = 0\). But 0 is not in the domain of \(f\), so 0 is not a critical number. It still goes on the sign chart as a break point, because \(f'\) can change sign there.
How to find where f is increasing and decreasing (the sign chart)
  1. Find the domain of \(f\). Write down every number that is not in the domain (zeros of a denominator, places where a logarithm's input is not positive).
  2. Compute \(f'(x)\). Combine it into a single fraction and factor the numerator and the denominator completely. Pull out common factors such as \(e^{x}\) or \(x^{-1/3}\).
  3. Find the critical numbers: the zeros of the numerator of \(f'\) that are in the domain, and the zeros of the denominator of \(f'\) that are in the domain of \(f\).
  4. Mark the critical numbers and the numbers outside the domain on a number line, in increasing order. They cut the domain into open intervals.
  5. In each interval, pick one test value. Record the sign of each factor of \(f'\) at that test value, then multiply the signs to get the sign of \(f'\). A factor that is positive everywhere, such as \(e^{x}\), \(x^2 + 1\), or a square like \((x - 1)^2\), never changes a sign, so say once that it is positive and move on.
  6. Where \(f' \gt 0\), \(f\) is increasing. Where \(f' \lt 0\), \(f\) is decreasing. Write the answer as open intervals. If two neighboring intervals have the same sign and the number between them is in the domain of \(f\), the textbook joins them into one interval (as with \(x^3\) below). Never join two intervals across a number that is not in the domain.
Worked example 1

Find the open intervals where \(f(x) = x^3 - 12x + 1\) is increasing and where it is decreasing.

How to spot this type: the question asks for "intervals where \(f\) is increasing and decreasing" and \(f\) is a polynomial, so the method is a sign chart of \(f'\) whose only break points are the zeros of \(f'\).

Relative extrema

Here are the professor's definitions. \(f(c)\) is a relative (or local) maximum of \(f\) if there is an open interval containing \(c\) on which \(f(c) \ge f(x)\) for every \(x\). In words, the point \((c, f(c))\) is at least as high as every nearby point on the graph. It is the top of a hill. \(f(c)\) is a relative (or local) minimum if there is an open interval containing \(c\) on which \(f(c) \le f(x)\). It is the bottom of a valley. Both kinds are called relative extrema (one of them is a relative extremum). A relative maximum does not have to be the highest point of the whole graph. The highest point of the whole graph is called an absolute maximum, and that comes in Section 6.1.

Notice the difference between where an extremum occurs and what it is. "The relative maximum occurs at \(x = -2\)" names the location. "The relative maximum value is 17" names the height \(f(-2)\). Questions often ask for both.

Fermat's Theorem

If \(f\) has a local maximum or minimum at \(c\), and if \(f'(c)\) exists, then \(f'(c) = 0\). Rephrased: if \(f\) has a local extreme value at \(c\), then \(c\) is a critical number of \(f\).

In plain words: at the top of a smooth hill or the bottom of a smooth valley, the tangent line is flat. So the only places where hills and valleys can happen are the critical numbers.

So relative extrema can only happen at critical numbers. The critical numbers are the candidates; you still have to test each one. Two cautions from lecture:

  • A critical number does not have to be an extremum. For \(f(x) = x^3\), \(f'(x) = 3x^2\) and \(f'(0) = 0\), so 0 is a critical number. But \(3x^2 \gt 0\) on both sides of 0, so the graph rises, flattens for an instant at the origin, and keeps rising. There is no hill and no valley at 0. The textbook says \(x^3\) is increasing on \((-\infty, \infty)\). The same happens for \(x^{1/3}\): its derivative \(\dfrac{1}{3x^{2/3}}\) is positive on both sides of 0, so it is increasing on \((-\infty, \infty)\) with no extremum.
  • An extremum can happen where \(f'\) does not exist. For \(f(x) = |x|\), the graph has a sharp corner at 0, \(f'(0)\) does not exist, and 0 is a relative (and absolute) minimum.
First Derivative Test

Let \(c\) be a critical number of a continuous function \(f\).

  • If \(f'\) changes from positive to negative at \(c\), then \(f\) has a local maximum at \(c\).
  • If \(f'\) changes from negative to positive at \(c\), then \(f\) has a local minimum at \(c\).
  • If \(f'\) does not change sign at \(c\), then \(f\) does not have a local maximum or minimum at \(c\).

In plain words: uphill and then downhill makes a hilltop, which is a maximum. Downhill and then uphill makes a valley bottom, which is a minimum. Going the same direction on both sides makes neither.

The picture behind it: positive then negative means the graph goes up and then down, which makes a hill. Negative then positive means down and then up, which makes a valley. The test only applies at a number in the domain. At a vertical asymptote the sign of \(f'\) can change, but there is no point on the graph, so there is no extremum there.

What to write on the exam. Name the sign change and the conclusion in one sentence, for example: "\(f\) has a relative maximum at \(x = 2\) because \(f'\) changes from positive to negative there." For a minimum: "\(f\) has a relative minimum at \(x = 5\) because \(f'\) changes from negative to positive there." For a critical number that is not an extremum: "\(f\) has no relative extremum at \(x = 0\) because \(f'\) is negative on both sides of 0." Then give the value, for example "the relative maximum value is \(f(2) = 7\)." A sign chart with no sentence leaves the reasoning unstated.

Back to Worked example 1: the chart shows \(f'\) changes from positive to negative at \(x = -2\), so \(f\) has a relative maximum there with value \(f(-2) = 17\). It shows \(f'\) changes from negative to positive at \(x = 2\), so \(f\) has a relative minimum there with value \(f(2) = -15\).

Worked example 2

Find all relative extrema of \(f(x) = 3x^4 - 8x^3 + 5\), and give the open intervals where \(f\) is increasing and decreasing.

Rational functions: a vertical asymptote splits the chart

For a quotient, any zero of the denominator of \(f\) is outside the domain. It is never a critical number, but \(f'\) can change sign there, so it must appear on the sign chart. The intervals on either side of it are always listed separately.

Worked example 3

Fractional powers

Here \(x^{1/3}\) means the real cube root \(\sqrt[3]{x}\), which is defined for negative numbers too: \((-8)^{1/3} = -2\). Also \(x^{2/3} = \left(\sqrt[3]{x}\right)^2\), which is never negative. When you differentiate, negative exponents appear, such as \(x^{-1/3} = \dfrac{1}{x^{1/3}}\). Rewrite them as fractions so you can see where \(f'\) does not exist. Those numbers are critical numbers whenever \(f\) itself is defined there.

Worked example 4

Let \(f(x) = x^{2/3}(x - 5)\). Find the critical numbers, the open intervals where \(f\) is increasing and decreasing, and all relative extrema.

How to spot this type: a fractional power such as \(x^{2/3}\) means \(f'\) will contain \(x\) to a negative power. So look for numbers where \(f'\) does not exist, not only numbers where \(f' = 0\).

  1. Find the domain. The cube root is defined for every real number, so the domain is \((-\infty, \infty)\).
  2. Differentiate with the product rule. Set \(u = x^{2/3}\), \(v = x - 5\), \(u' = \tfrac23 x^{-1/3}\), \(v' = 1\). Then \(f' = u'v + uv'\). \[f'(x) = \tfrac23 x^{-1/3}(x - 5) + x^{2/3}(1).\]
  3. Write both terms over the common denominator \(3x^{1/3}\). The first term is \(\dfrac{2(x - 5)}{3x^{1/3}}\). For the second, \(x^{2/3} = \dfrac{x^{2/3}\cdot 3x^{1/3}}{3x^{1/3}} = \dfrac{3x}{3x^{1/3}}\). \[\begin{aligned} f'(x) &= \frac{2(x - 5)}{3x^{1/3}} + \frac{3x}{3x^{1/3}}\\ &= \frac{2x - 10 + 3x}{3x^{1/3}}\\ &= \frac{5x - 10}{3x^{1/3}}\\ &= \frac{5(x - 2)}{3x^{1/3}}. \end{aligned}\]
  4. Find the critical numbers. The numerator is 0 at \(x = 2\). The denominator is 0 at \(x = 0\), so \(f'(0)\) does not exist, and \(f(0) = 0\) is defined, so 0 is a critical number too. The critical numbers are \(x = 0\) and \(x = 2\).

Exponentials and logarithms

Three facts do most of the work. First, \(e^{\text{anything}} \gt 0\), so a factor like \(e^{x}\), \(e^{-x}\), or \(e^{x^2}\) is always positive and never creates a critical number. Second, \(\ln x\) is only defined for \(x \gt 0\), so a function with \(\ln x\) in it has domain inside \((0, \infty)\). Third, \(\ln x \lt 0\) for \(0 \lt x \lt 1\), \(\ln 1 = 0\), and \(\ln x \gt 0\) for \(x \gt 1\); to solve \(\ln x = k\), write \(x = e^{k}\). Good test values for logarithms are powers of \(e\), such as \(e^{-1}\), \(1\), and \(e\), because their logarithms are \(-1\), 0, and 1.

That is the function in part (a) below, since \(\dfrac{x^2}{e^{x}} = x^2e^{-x}\). Level 4 practices more questions of that kind.

Reading the answer from a graph of f or a graph of f'

If you are shown the graph of \(f\), read it left to right: \(f\) is increasing where the curve goes up and decreasing where it goes down, and the turning points are the relative extrema. If you are shown the graph of \(f'\), the question is different. Now you look at whether the curve is above or below the \(x\)-axis. Above the axis means \(f' \gt 0\), so \(f\) is increasing. Below the axis means \(f' \lt 0\), so \(f\) is decreasing. A relative extremum of \(f\) happens where the graph of \(f'\) crosses the axis. Where the graph of \(f'\) only touches the axis and turns back, the sign does not change, so there is no extremum there.

A business application: when is profit increasing

Profit is \(P(x) = R(x) - C(x)\), revenue minus cost, where \(x\) is the number of units. Profit is increasing exactly where \(P'(x) \gt 0\). Since \(P'(x) = R'(x) - C'(x)\), that is the same as \(R'(x) \gt C'(x)\): profit grows while each extra unit brings in more revenue (marginal revenue) than it costs to make (marginal cost). The domain in a word problem is usually \(x \ge 0\), so the sign chart starts at 0.

Worked example 7

A company makes \(x\) thousand units of a product, \(x \ge 0\). Its revenue is \(R(x) = 30x\) and its cost is \(C(x) = x^3 - 6x^2 + 15x + 20\), both in thousands of dollars. Rolle's Theorem and the Mean Value Theorem

Lecture 14 uses the Mean Value Theorem to prove the increasing and decreasing test, and the theorem is also asked about by itself. Two kinds of questions use it. One kind gives a function and an interval and asks for the number \(c\) that the theorem promises. The other kind gives a bound on \(f'\) and asks how large or how small a value of \(f\) can be.

Rolle's Theorem

Suppose \(f\) is continuous on \([a, b]\), differentiable on \((a, b)\), and \(f(a) = f(b)\). Then there is at least one number \(c\) in \((a, b)\) with \(f'(c) = 0\).

In plain words: if a smooth curve starts and ends at the same height, then somewhere in between it has a flat tangent line.

Mean Value Theorem (MVT)

Suppose \(f\) is continuous on \([a, b]\) and differentiable on \((a, b)\). Then there is at least one number \(c\) in \((a, b)\) with \[f'(c) = \frac{f(b) - f(a)}{b - a}, \qquad\text{or equivalently}\qquad f(b) - f(a) = f'(c)\,(b - a).\]

In plain words: somewhere between the two endpoints, the slope of the curve equals the average slope, which is the slope of the straight line joining the two endpoints. If you drive 120 miles in 2 hours, then at some moment your speedometer reads exactly 60 miles per hour.

The conditions after "suppose" are called the hypotheses. Polynomials, \(e^{x}\), \(\sin x\), and \(\cos x\) are continuous and differentiable everywhere, so the hypotheses hold automatically for them on any interval. For a bound question, write the theorem in the form \(f(b) - f(a) = f'(c)(b - a)\), then replace \(f'(c)\) by the largest or smallest value it is allowed to have.

A related argument shows that an equation has exactly one solution. If \(f' \gt 0\) everywhere, then \(f\) is increasing, so its graph can cross the \(x\)-axis at most once. If also \(f\) is negative at one number and positive at another, the Intermediate Value Theorem says the graph crosses the axis between them. Together these give exactly one solution. Level 5 practices this.

Worked example 8

Let \(f(x) = x^2 - 4x\). (a) Check that Rolle's Theorem applies to \(f\) on \([0, 4]\), and find the number \(c\) it gives. (b) Find every number \(c\) that the Mean Value Theorem gives for \(f\) on \([1, 5]\). (c) A different function \(g\) is differentiable everywhere, \(g(1) = 3\), and \(g'(x) \le 2\) for all \(x\). How large can \(g(5)\) possibly be?

How to spot this type: "check that the theorem applies" and "find the number \(c\)" signal Rolle or the MVT. The words "how large can it possibly be" together with an inequality for the derivative signal an MVT bound.

  1. (a) Check the hypotheses. \(f\) is a polynomial, so it is continuous on \([0, 4]\) and differentiable on \((0, 4)\). Compare the endpoint values. \[f(0) = 0^2 - 4(0) = 0, \qquad f(4) = 16 - 16 = 0.\] They are equal, so Rolle's Theorem applies.
  2. (a) Find \(c\). Set the derivative equal to 0. \[f'(x) = 2x - 4 = 0 \quad\text{gives}\quad x = 2.\] The number 2 lies in \((0, 4)\), so \(c = 2\).
  3. (b) Compute the average rate of change on \([1, 5]\). \[f(5) = 25 - 20 = 5, \qquad f(1) = 1 - 4 = -3, \qquad \frac{f(5) - f(1)}{5 - 1} = \frac{5 - (-3)}{4} = \frac{8}{4} = 2.\]
  4. (b) Solve \(f'(c) = 2\) and keep only solutions inside \((1, 5)\). \[\begin{aligned} 2c - 4 &= 2\\ 2c &= 6\\ c &= 3. \end{aligned}\] The number 3 lies in \((1, 5)\). The picture shows the tangent line at \(x = 3\) is parallel to the line joining the endpoints.
  5. (c) Apply the MVT to \(g\) on \([1, 5]\). It gives a number \(c\) between 1 and 5 with \[g(5) - g(1) = g'(c)\,(5 - 1) = 4g'(c).\]
  6. (c) Use the bound \(g'(c) \le 2\). \[\begin{aligned} g(5) - 3 &= 4g'(c) \le 4(2) = 8\\ g(5) &\le 3 + 8 = 11. \end{aligned}\] The value 11 really happens: \(g(x) = 2x + 1\) has \(g(1) = 3\), \(g'(x) = 2\), and \(g(5) = 11\).

Answer: (a) \(c = 2\). (b) \(c = 3\). (c) \(g(5)\) can be at most 11.

Common mistake. Keeping a value of \(c\) that is outside the open interval \((a, b)\). Solve \(f'(c) = \) (average slope), then throw away any solution that is not strictly between \(a\) and \(b\).
Common mistake. Going backward in a bound question without care. If you know \(g(1)\) and want \(g(0)\), the MVT gives \(g(1) - g(0) = g'(c)(1 - 0)\), so an upper bound on \(g'\) gives a lower bound on \(g(0)\). Always write the equation first, then solve for the unknown value.

More common mistakes

Common mistake. Forgetting to put numbers outside the domain on the chart. For \(f(x) = \dfrac{3}{x + 2}\), \(f'(x) = -\dfrac{3}{(x + 2)^2}\) is never 0 and there are no critical numbers, but the answer is "decreasing on \((-\infty, -2)\) and \((-2, \infty)\)," never "decreasing on \((-\infty, \infty)\)."
Common mistake. Dividing both sides of \(f'(x) = 0\) by a factor that can be 0. In \(x^2 e^{-x}(3 - x) = 0\), dividing by \(x^2\) loses the critical number 0. Factor and set each factor equal to 0 instead.
Common mistake. Simplifying \(f'\) incorrectly and then building a perfect chart for the wrong derivative. Check your factored \(f'\) by plugging one number into both the unfactored and the factored forms; they must agree.
If you get stuck
  • Write \(f'\) as one fraction, then factor the top and the bottom completely. Pull out common pieces such as \(e^{x}\), \(x^2\), or the lowest power of \(x\) first.
  • Make one list of every break point: zeros of the top of \(f'\), zeros of the bottom of \(f'\), and numbers outside the domain of \(f\). Put them all on one number line in increasing order.
  • Mark the factors that can never be negative (\(e^{\text{anything}}\), a square, \(x^2 + 1\), \(x^{2/3}\)) as \(+\) and stop thinking about them. The sign of \(f'\) comes from the other factors.
  • If a quadratic in \(f'\) will not factor, use the quadratic formula. If \(b^2 - 4ac \lt 0\), the quadratic has no zeros and keeps one sign everywhere.
  • If you cannot tell where a number like \(\sqrt3\) or \(e^{-1/2}\) sits, trap it between two easy numbers (for example \(1.7^2 = 2.89 \lt 3 \lt 3.24 = 1.8^2\)), then pick test values on each side.
  • If the problem gives a picture, ask first: is this the graph of \(f\) or of \(f'\)? For \(f\), look at up and down. For \(f'\), look at above and below the axis.
Quick check
Can a critical number fail to be a relative extremum? Give an example.

Yes. For \(f(x) = x^3\), \(f'(0) = 0\), but \(f'(x) = 3x^2 \gt 0\) on both sides of 0, so the sign does not change and there is no extremum at 0.

If \(f'(x) \gt 0\) for every \(x\) in \((0, 5)\), must \(f(x)\) be positive on \((0, 5)\)?

No. \(f(x) = x - 10\) has \(f'(x) = 1 \gt 0\), but \(f(1) = -9 \lt 0\). The sign of \(f'\) tells you direction, not height.

Is \(x = 3\) a critical number of \(f(x) = \dfrac{1}{(x - 3)^2}\)?

No. \(f'(x) = -\dfrac{2}{(x - 3)^3}\) does not exist at 3, but 3 is not in the domain of \(f\). It still goes on the sign chart as a break point.

The graph of \(f'\) crosses the \(x\)-axis from below to above at \(x = 2\). What does \(f\) have at 2?

A relative minimum, because \(f'\) changes from negative to positive at 2, so \(f\) goes down and then up.

Where is \(f(x) = ax^2 + bx + c\) with \(a \gt 0\) decreasing?

\(f'(x) = 2ax + b \lt 0\) exactly when \(x \lt -\tfrac{b}{2a}\), so \(f\) is decreasing on \(\left(-\infty, -\tfrac{b}{2a}\right)\) and increasing after it. The relative minimum is at the vertex \(x = -\tfrac{b}{2a}\).

What to have memorized
  • Increasing on an interval means \(f(x_1) \lt f(x_2)\) whenever \(x_1 \lt x_2\); decreasing means \(f(x_1) \gt f(x_2)\).
  • If \(f' \gt 0\) on an interval, \(f\) is increasing there. If \(f' \lt 0\), \(f\) is decreasing. If \(f' = 0\) on the whole interval, \(f\) is constant.
  • A critical number is a number \(c\) in the domain of \(f\) where \(f'(c) = 0\) or \(f'(c)\) does not exist.
  • Fermat's Theorem: every relative extremum happens at a critical number. The converse (the reverse statement, "every critical number is an extremum") is false: \(x^3\) at 0.
  • The sign chart recipe: domain, factor \(f'\), critical numbers and points outside the domain, one test value per interval, sign of each factor, answer in open intervals.
  • First Derivative Test: \(f'\) from \(+\) to \(-\) gives a relative maximum, from \(-\) to \(+\) gives a relative minimum, no sign change gives no extremum.
  • The sentence: "\(f\) has a relative maximum at \(x = c\) because \(f'\) changes from positive to negative there," followed by the value \(f(c)\).
  • \(e^{\text{anything}} \gt 0\); \(\ln x\) needs \(x \gt 0\); \(\ln x\) is negative on \((0, 1)\) and positive on \((1, \infty)\).
  • Never join intervals across a vertical asymptote or any number outside the domain.
  • Rolle's Theorem: continuous on \([a, b]\), differentiable on \((a, b)\), and \(f(a) = f(b)\) give some \(c\) in \((a, b)\) with \(f'(c) = 0\).
  • Mean Value Theorem: continuous on \([a, b]\) and differentiable on \((a, b)\) give some \(c\) in \((a, b)\) with \(f(b) - f(a) = f'(c)(b - a)\).

Problem 25
Decide whether each statement is true or false. If it is true, explain why. If it is false, give a specific function that shows it is false. (a) If \(f'(x) \lt 0\) for every \(x\) in an interval, then \(f(x) \lt 0\) on that interval. (b) If \(f\) is increasing on \((-1, 1)\), then \(f'(x) \gt 0\) for every \(x\) in \((-1, 1)\). (d) If \(f\) is increasing on \([0, 2]\) and increasing on \((2, 5]\), then \(f\) is increasing on \([0, 5]\). (f) A relative minimum value of a function can never be larger than one of its relative maximum values.

For each false statement, try a simple function: a line, \(x^3\), a function with a jump, or one of the rational functions with an asymptote from this unit.
Show full solution
  1. (a) False. Take \(f(x) = 5 - x\) on \((0, 1)\). Then \(f'(x) = -1 \lt 0\), but \(f\left(\tfrac12\right) = \tfrac92 \gt 0\). A negative derivative says the graph is going down, not that it is below the axis.
  2. (b) False. Take \(f(x) = x^3\). It is increasing on \((-1, 1)\) (the lesson shows \(x^3\) is increasing on the whole line), but \(f'(0) = 3(0)^2 = 0\), which is not positive.   3. (c) True. Take any \(x_1 \lt x_2\) in \([0, 5]\). If both are in \([0, 2]\) or both are in \([2, 5]\), then \(f(x_1) \lt f(x_2)\) directly. Otherwise \(x_1 \lt 2 \lt x_2\). Then \(f(x_1) \lt f(2)\) because \(f\) is increasing on \([0, 2]\), and \(f(2) \lt f(x_2)\) because \(f\) is increasing on \([2, 5]\). Problem 28

  2. (a) Complete the square inside the parentheses.
