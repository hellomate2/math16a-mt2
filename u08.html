Section 6.1: Absolute extrema

The big idea

This section answers one question: on a given interval, what is the highest value \(f\) ever reaches, and what is the lowest? On a closed interval \([a, b]\) those can only happen at a critical number or at an endpoint, so you plug that short list of numbers into \(f\) and pick the largest and the smallest. The one thing to remember is to plug in the endpoints, and when the interval has no endpoints, to use the critical point theorem instead.

Absolute extrema and relative extrema

In Section 5.2 you found relative extrema: the tops of hills and the bottoms of valleys on a graph. Section 6.1 looks at every value the function takes on a given set and picks out the very largest one and the very smallest one. Those two values are the absolute extrema (extrema is the plural of extremum, which means a maximum or a minimum). You need them in every optimization problem. The reason is that "the most profit" or "the least material" means the largest or smallest value of a function over all allowed inputs, and not only the largest value near one point.

Here are the professor's definitions. The set \(S\) is usually an interval, for example \([0, 5]\) or \((0, \infty)\).

Absolute extrema on a set S

Let \(S\) be part of the domain of \(f\) and let \(c\) be a number in \(S\).

  • \(f(c)\) is the absolute maximum value of \(f\) on \(S\) if \(f(c) \ge f(x)\) for all \(x\) in \(S\). We also say that \(f\) attains its maximum value at \(c\).
  • \(f(c)\) is the absolute minimum value of \(f\) on \(S\) if \(f(c) \le f(x)\) for all \(x\) in \(S\). We also say that \(f\) attains its minimum value at \(c\).

The maximum and minimum values are called the extreme values of \(f\) on \(S\).

In plain words: the absolute maximum is the greatest height the graph reaches anywhere on the set, and the absolute minimum is the lowest height. Both are heights, that is, values of \(f\). The \(x\) where each one happens is a separate part of the answer, and you should give both.

Relative (local) extrema
  • \(f(c)\) is a relative maximum (or local maximum) of \(f\) if there is an open interval \((a, b)\) containing \(c\) such that \(f(c) \ge f(x)\) for all \(x\) in \((a, b)\).
  • \(f(c)\) is a relative minimum (or local minimum) of \(f\) if there is an open interval \((a, b)\) containing \(c\) such that \(f(c) \le f(x)\) for all \(x\) in \((a, b)\).

In plain words: a relative maximum is a hilltop and a relative minimum is a valley floor. A hilltop only has to be higher than the points right around it. It does not have to be higher than everything else on the graph.

The difference is the comparison group. A relative maximum only has to beat the points close to it. An absolute maximum has to beat every point in the whole set. The graph below shows \(f(x) = x^3 - 6x^2 + 9x + 1\) on the interval \([0, 5]\). Its derivative is \(f'(x) = 3x^2 - 12x + 9 = 3(x - 1)(x - 3)\), so the hill and the valley sit at \(x = 1\) and \(x = 3\).

Read the picture carefully, because it shows three facts at once.

  • The point \((1, 5)\) is a relative maximum, since it is higher than every point near it. It is not the absolute maximum, since \(f(5) = 125 - 150 + 45 + 1 = 21\) is bigger than 5.
  • The absolute maximum value is 21, attained at the endpoint \(x = 5\). The graph is not at the top of a hill there. It is the highest point only because the interval stops at \(x = 5\). This is why endpoints must always be checked.
  • The absolute minimum value is 1, and it is attained at two numbers: \(f(0) = 1\) and \(f(3) = 27 - 54 + 27 + 1 = 1\). On a set, a function has at most one absolute maximum value and at most one absolute minimum value. Each of those values can still be attained at more than one \(x\). When that happens, your answer must list every \(x\).

Absolute and relative extreme values may or may not exist. A function can have many relative extrema, or none at all.

The extreme value theorem

Before you search for an absolute maximum, it helps to know whether one exists. The extreme value theorem gives a simple condition that guarantees both.

Extreme value theorem

If \(f\) is continuous on a closed and bounded interval \([a, b]\), then \(f\) attains an absolute maximum value \(f(c)\) and an absolute minimum value \(f(d)\) at some numbers \(c\) and \(d\) in \([a, b]\).

In plain words: if you can draw the graph without lifting your pencil, and you look at it between two end points that are both included, then the graph must have a highest point and a lowest point.

The theorem has three conditions. The function must be continuous (no breaks, jumps, or vertical asymptotes on the interval). The interval must be closed (both endpoints are included). The interval must be bounded (both endpoints are real numbers, not \(\infty\) or \(-\infty\)). Together these say the interval has the form \([a, b]\). If any one condition fails, the guarantee is gone. Here is a counterexample for each.

Continuity fails. Let \(f(x) = \dfrac{1}{x}\) on \([-1, 1]\). The interval is closed and bounded, but \(f\) is not defined at \(x = 0\), so it is not continuous on \([-1, 1]\). As \(x\) approaches 0 from the right, \(\tfrac{1}{x}\) grows past every number, so there is no absolute maximum. As \(x\) approaches 0 from the left, \(\tfrac{1}{x}\) drops below every number, so there is no absolute minimum either.

The interval is not closed. Let \(f(x) = x^2\) on the open interval \((0, 2)\). This function is continuous everywhere. Its values get as close as you like to 0 (near \(x = 0\)) and to 4 (near \(x = 2\)), but the endpoints are not in the interval, so the values 0 and 4 are never reached. For any \(x\) in \((0, 2)\) you can pick a number between \(x\) and 2, and \(f\) is larger there. So \(f\) has no absolute maximum on \((0, 2)\), and for the same reason, using numbers between 0 and \(x\), it has no absolute minimum.

The interval is not bounded. Let \(f(x) = x\) on \([0, \infty)\). This is continuous, and the interval includes its one endpoint, but the interval goes on forever. The values \(f(x) = x\) grow without bound, so there is no absolute maximum. (There is an absolute minimum, \(f(0) = 0\).)

Common mistake. Reading the theorem backwards. The theorem says the hypotheses guarantee a max and a min. It does not say that a function failing the hypotheses has no extrema. For example, \(f(x) = x^2\) on \((-1, 1)\) is on an open interval, yet it has an absolute minimum value 0 at \(x = 0\). When the hypotheses fail, you have to investigate instead of quoting the theorem.

Where absolute extrema can happen

Recall from Section 5.1 that a critical number of \(f\) is a number \(c\) in the domain of \(f\) where either \(f'(c) = 0\) or \(f'(c)\) does not exist. Fermat's theorem (also from Section 5.1) says that if \(f\) has a relative extremum at \(c\), then \(c\) is a critical number.

In plain words: a critical number is an \(x\) where the graph is flat (slope zero), or where it has a sharp point or a vertical tangent (no slope at all), and \(f\) itself is defined there. Every hilltop and every valley floor sits at a critical number.

Now take a continuous \(f\) on \([a, b]\) and suppose its absolute maximum is attained at some number \(c\). There are only two possibilities.

  • If \(c\) is strictly inside the interval, then \(f(c)\) beats every nearby point, so it is also a relative maximum. Fermat's theorem then says \(c\) is a critical number.
  • Otherwise \(c\) is one of the endpoints \(a\) or \(b\).

The same reasoning works for the absolute minimum. So the absolute extrema can only happen at critical numbers inside the interval or at the endpoints. We call these numbers the candidates. That short list of candidates is the whole idea of the closed interval method.

How to find absolute extrema on a closed interval [a, b] (the closed interval method)
  1. Check that \(f\) is continuous on \([a, b]\). Then the extreme value theorem says the absolute maximum and minimum exist.
  2. Compute \(f'(x)\) and simplify it into one factored fraction if you can.
  3. Find the critical numbers: solve \(f'(x) = 0\), and also find every \(x\) in the domain of \(f\) where \(f'(x)\) does not exist (usually where a denominator of \(f'\) is zero).
  4. Throw out every critical number that is not in the open interval \((a, b)\). Say in writing that you are throwing it out.
  5. Make a value table: evaluate \(f\) at each remaining critical number and at both endpoints \(a\) and \(b\).
  6. The largest value in the table is the absolute maximum value, and the smallest is the absolute minimum value. State each value and every \(x\) where it is attained.

In plain words: list both endpoints and every critical number inside the interval, plug each one into \(f\), and read off the biggest output and the smallest output.

You never need a sign chart in this method. The value table does the comparing for you.

Worked example 1: a polynomial

Find the absolute maximum and minimum values of \(f(x) = 2x^3 - 3x^2 - 12x + 5\) on \([-2, 3]\).

How to spot this type: the word "absolute" together with a closed interval \([-2, 3]\), where both endpoints have square brackets, tells you to use the closed interval method.

  1. Check continuity. A polynomial is continuous everywhere, so \(f\) is continuous on the closed interval \([-2, 3]\), and the extreme value theorem says the absolute extrema exist.
  2. Differentiate with the power rule term by term, then factor out the common factor 6. \[\begin{aligned} f'(x) &= 6x^2 - 6x - 12 \\ &= 6(x^2 - x - 2) \\ &= 6(x - 2)(x + 1). \end{aligned}\]
  3. Find the critical numbers. A polynomial derivative exists everywhere, so the only critical numbers come from \(f'(x) = 0\): \[6(x - 2)(x + 1) = 0 \quad \text{gives} \quad x = 2 \ \text{or} \ x = -1.\] Both lie inside \((-2, 3)\), so both stay.
  4. Evaluate \(f\) at the critical numbers and the endpoints. \[\begin{aligned} f(-2) &= 2(-8) - 3(4) - 12(-2) + 5 = -16 - 12 + 24 + 5 = 1, \\ f(-1) &= 2(-1) - 3(1) - 12(-1) + 5 = -2 - 3 + 12 + 5 = 12, \\ f(2) &= 2(8) - 3(4) - 12(2) + 5 = 16 - 12 - 24 + 5 = -15, \\ f(3) &= 2(27) - 3(9) - 12(3) + 5 = 54 - 27 - 36 + 5 = -4. \end{aligned}\]
    \(x\)Why it is a candidate\(f(x)\)
    \(-2\)left endpoint\(1\)
    \(-1\)critical number\(12\) (largest)
    \(2\)critical number\(-15\) (smallest)
    \(3\)right endpoint\(-4\)
  5. Compare. The largest value is 12 at \(x = -1\) and the smallest is \(-15\) at \(x = 2\).

Answer: The absolute maximum value is 12, attained at \(x = -1\). The absolute minimum value is \(-15\), attained at \(x = 2\).

Worked example 2: a critical number outside the interval

Find the absolute maximum and minimum values of \(f(x) = x^3 - 12x + 1\) on \([0, 3]\).

How to spot this type: it is a closed interval again, but the interval starts at 0 and \(f'\) has a negative root. Any time you solve \(f'(x) = 0\), compare each root with the interval before you plug it in.

  1. Check continuity. \(f\) is a polynomial, so it is continuous on \([0, 3]\) and the absolute extrema exist.
  2. Differentiate and factor. \[\begin{aligned} f'(x) &= 3x^2 - 12 \\ &= 3(x^2 - 4) \\ &= 3(x - 2)(x + 2). \end{aligned}\]
  3. Find the critical numbers. \(f'(x) = 0\) gives \(x = 2\) or \(x = -2\). The number \(-2\) is not in \([0, 3]\), so we throw it out. The value \(f(-2)\) has nothing to do with this problem. Only \(x = 2\) stays.
  4. Evaluate \(f\) at the remaining critical number and the endpoints. \[\begin{aligned} f(0) &= 0 - 0 + 1 = 1, \\ f(2) &= 8 - 24 + 1 = -15, \\ f(3) &= 27 - 36 + 1 = -8. \end{aligned}\]
    \(x\)Why it is a candidate\(f(x)\)
    \(0\)left endpoint\(1\) (largest)
    \(2\)critical number\(-15\) (smallest)
    \(3\)right endpoint\(-8\)

Answer: The absolute maximum value is 1, attained at \(x = 0\). The absolute minimum value is \(-15\), attained at \(x = 2\).

Common mistake. Putting \(f(-2) = -8 + 24 + 1 = 17\) into the table in Example 2. It is bigger than every value in the table, so it would give the wrong absolute maximum. A critical number outside the interval is not a candidate.
Worked example 3: a critical number where f' does not exist

Find the absolute maximum and minimum values of \(f(x) = 3x^{2/3} - 2x\) on \([-1, 8]\).

How to spot this type: a fractional power such as \(x^{2/3}\) means \(f'\) will have a power of \(x\) in a denominator, so expect a critical number where \(f'\) does not exist, in addition to the ones where \(f' = 0\).

  1. Check continuity. \(x^{2/3} = \left(\sqrt[3]{x}\right)^2\) is defined and continuous for every real \(x\), including negative \(x\), because cube roots of negative numbers exist. So \(f\) is continuous on \([-1, 8]\) and the absolute extrema exist.
  2. Differentiate with the power rule. The new exponent is \(\tfrac{2}{3} - 1 = -\tfrac{1}{3}\), and \(3 \cdot \tfrac{2}{3} = 2\). \[\begin{aligned} f'(x) &= 3 \cdot \tfrac{2}{3}x^{-1/3} - 2 \\ &= 2x^{-1/3} - 2 \\ &= \frac{2}{x^{1/3}} - 2. \end{aligned}\]
  3. Write \(f'\) as one fraction so you can see both kinds of critical numbers. Use the common denominator \(x^{1/3}\). \[f'(x) = \frac{2}{x^{1/3}} - \frac{2x^{1/3}}{x^{1/3}} = \frac{2 - 2x^{1/3}}{x^{1/3}} = \frac{2\left(1 - x^{1/3}\right)}{x^{1/3}}.\]
  4. Find where \(f'(x) = 0\). A fraction is zero when its numerator is zero. \[1 - x^{1/3} = 0 \quad \text{gives} \quad x^{1/3} = 1, \quad \text{so} \quad x = 1^3 = 1.\]
  5. Find where \(f'(x)\) does not exist. The denominator \(x^{1/3}\) is zero at \(x = 0\). The function itself is defined there, since \(f(0) = 0\), so \(x = 0\) is a critical number. Both \(0\) and \(1\) are inside \((-1, 8)\).
  6. Evaluate \(f\) at the critical numbers and the endpoints. Use \(\sqrt[3]{-1} = -1\) and \(\sqrt[3]{8} = 2\). \[\begin{aligned} f(-1) &= 3(-1)^2 - 2(-1) = 3 + 2 = 5, \\ f(0) &= 3 \cdot 0 - 0 = 0, \\ f(1) &= 3(1)^2 - 2(1) = 3 - 2 = 1, \\ f(8) &= 3(2)^2 - 2(8) = 12 - 16 = -4. \end{aligned}\]
    \(x\)Why it is a candidate\(f(x)\)
    \(-1\)left endpoint\(5\) (largest)
    \(0\)critical number (\(f'\) does not exist)\(0\)
    \(1\)critical number (\(f' = 0\))\(1\)
    \(8\)right endpoint\(-4\) (smallest)
  7. Compare. The graph has a sharp point (a cusp) at \(x = 0\), where the tangent line would be vertical. That point is a relative minimum, but it is not the absolute minimum on this interval. Both absolute extrema happen at endpoints.

Answer: The absolute maximum value is 5, attained at \(x = -1\). The absolute minimum value is \(-4\), attained at \(x = 8\).

Common mistake. Solving only \(f'(x) = 0\) and missing \(x = 0\). With fractional powers, always rewrite \(f'\) with positive exponents as one fraction and check where its denominator is zero. A second mistake goes the other way: a number where \(f\) itself is undefined (like \(x = 0\) for \(f(x) = \tfrac{1}{x}\)) is not a critical number, because a critical number must be in the domain of \(f\).
Worked example 4: an exponential function

Find the absolute maximum and minimum values of \(f(x) = xe^{-x/2}\) on \([0, 4]\).

How to spot this type: a closed interval and a product of \(x\) with an exponential. Use the closed interval method, take the derivative with the product rule, and factor out the exponential, which is never zero.

  1. Check continuity. \(x\) and \(e^{-x/2}\) are continuous everywhere, so their product is continuous on \([0, 4]\) and the absolute extrema exist.
  2. Differentiate with the product rule. Let \(u = x\) and \(v = e^{-x/2}\). Then \(u' = 1\) and, by the chain rule, \(v' = e^{-x/2} \cdot \left(-\tfrac{1}{2}\right) = -\tfrac{1}{2}e^{-x/2}\). \[\begin{aligned} f'(x) &= u'v + uv' \\ &= 1 \cdot e^{-x/2} + x\left(-\tfrac{1}{2}e^{-x/2}\right) \\ &= e^{-x/2}\left(1 - \tfrac{x}{2}\right). \end{aligned}\]
  3. Find the critical numbers. The factor \(e^{-x/2}\) is never zero (an exponential is always positive), so \(f'(x) = 0\) only when \(1 - \tfrac{x}{2} = 0\), which gives \(x = 2\). The derivative exists for every \(x\). So \(x = 2\) is the only critical number, and it is inside \((0, 4)\).
  4. Evaluate \(f\) at the critical number and the endpoints. \[\begin{aligned} f(0) &= 0 \cdot e^{0} = 0, \\ f(2) &= 2e^{-1} = \frac{2}{e}, \\ f(4) &= 4e^{-2} = \frac{4}{e^2}. \end{aligned}\]
  5. Compare without a calculator. Both \(\tfrac{2}{e}\) and \(\tfrac{4}{e^2}\) are positive, so 0 is the smallest. To compare the other two, write \(\tfrac{4}{e^2} = \tfrac{2}{e} \cdot \tfrac{2}{e}\). Since \(e \approx 2.72\) is bigger than 2, the factor \(\tfrac{2}{e}\) is less than 1, and multiplying a positive number by something less than 1 makes it smaller. So \(\tfrac{4}{e^2} \lt \tfrac{2}{e}\). (As decimals, \(\tfrac{2}{e} \approx 0.74\) and \(\tfrac{4}{e^2} \approx 0.54\).)

    \(0\)left endpoint\(0\) (smallest)
    \(2\)critical number\(\tfrac{2}{e} \approx 0.74\) (largest)
    \(4\)right endpoint\(\tfrac{4}{e^2} \approx 0.54\)

Answer: The absolute maximum value is \(\dfrac{2}{e}\), attained at \(x = 2\). The absolute minimum value is 0, attained at \(x = 0\).

Worked example 5: a trig function on [0, 2π]

Find the absolute maximum and minimum values of \(f(x) = \sin x + \cos x\) on \([0, 2\pi]\).

How to spot this type: sine and cosine on the closed interval \([0, 2\pi]\). It is the closed interval method, and the trig equation \(f'(x) = 0\) will have more than one solution in the interval, so look for all of them.

  1. Check continuity. Sine and cosine are continuous everywhere, so \(f\) is continuous on \([0, 2\pi]\) and the absolute extrema exist.
  2. Differentiate. The derivative of \(\sin x\) is \(\cos x\) and the derivative of \(\cos x\) is \(-\sin x\). \[f'(x) = \cos x - \sin x.\]
  3. Set \(f'(x) = 0\). \[\cos x - \sin x = 0 \quad \text{means} \quad \sin x = \cos x.\] At the numbers where \(\cos x = 0\), namely \(x = \tfrac{\pi}{2}\) and \(x = \tfrac{3\pi}{2}\), we have \(\sin x = \pm 1\), so the equation fails there. That means we may divide both sides by \(\cos x\): \[\frac{\sin x}{\cos x} = 1, \quad \text{that is,} \quad \tan x = 1.\]
  4. List every solution in the interval. Tangent equals 1 at \(x = \tfrac{\pi}{4}\) (first quadrant, where sine and cosine are both \(\tfrac{\sqrt{2}}{2}\)) and at \(x = \tfrac{5\pi}{4}\) (third quadrant, where both are \(-\tfrac{\sqrt{2}}{2}\)). The next solution, \(\tfrac{9\pi}{4}\), is past \(2\pi\). The derivative exists everywhere, so the critical numbers are \(\tfrac{\pi}{4}\) and \(\tfrac{5\pi}{4}\).
  5. Evaluate \(f\) at the critical numbers and the endpoints. \[\begin{aligned} f(0) &= \sin 0 + \cos 0 = 0 + 1 = 1, \\ f\left(\tfrac{\pi}{4}\right) &= \tfrac{\sqrt{2}}{2} + \tfrac{\sqrt{2}}{2} = \sqrt{2}, \\ f\left(\tfrac{5\pi}{4}\right) &= -\tfrac{\sqrt{2}}{2} - \tfrac{\sqrt{2}}{2} = -\sqrt{2}, \\ f(2\pi) &= \sin 2\pi + \cos 2\pi = 0 + 1 = 1. \end{aligned}\]
    \(x\)Why it is a candidate\(f(x)\)
    \(0\)left endpoint\(1\)
    \(\tfrac{\pi}{4}\)critical number\(\sqrt{2} \approx 1.41\) (largest)
    \(\tfrac{5\pi}{4}\)critical number\(-\sqrt{2} \approx -1.41\) (smallest)
    \(2\pi\)right endpoint\(1\)

Answer: The absolute maximum value is \(\sqrt{2}\), attained at \(x = \dfrac{\pi}{4}\). The absolute minimum value is \(-\sqrt{2}\), attained at \(x = \dfrac{5\pi}{4}\).

Common mistake. Stopping at the first solution of a trig equation. On \([0, 2\pi]\), equations like \(\tan x = 1\), \(\sin x = \tfrac{1}{2}\), or \(\cos x = \tfrac{1}{2}\) each have two solutions. Find the reference angle, then use the quadrants where the function has the right sign.
What to write on the exam. Start with a sentence such as "\(f\) is continuous on the closed interval \([-2, 3]\), so by the extreme value theorem it has an absolute maximum and an absolute minimum, and they occur at critical numbers in \((-2, 3)\) or at the endpoints." Show the derivative, name each critical number, say which ones you discard and why, show the arithmetic for every value in your table, and finish with a sentence that gives both the value and the \(x\): "The absolute maximum value is 12, attained at \(x = -1\)."

Reading absolute extrema from a graph

When a problem gives you a graph instead of a formula, the absolute maximum is the \(y\)-coordinate of the highest point of the graph over the given interval, and the absolute minimum is the \(y\)-coordinate of the lowest point. Look at the endpoints as well as the hills and valleys. A filled dot at an end means that endpoint is included and can be the answer. An open dot means the point is missing, so its height is never attained. An arrow means the graph keeps going, so look at where it heads. The first graph on this page is a good model: the highest point is the endpoint \((5, 21)\), and the lowest height, 1, is reached at two places.

Intervals that are not closed: the critical point theorem

Many applied problems live on intervals like \(x \gt 0\), written \((0, \infty)\). The extreme value theorem does not apply, and there are no endpoints to plug in. When there is only one critical number, the following theorem settles the question.

Critical point theorem

Suppose \(f\) is continuous on an interval \(I\) and has exactly one critical number in \(I\), say at \(c\).

  • If \(f\) has a relative maximum at \(x = c\), then \(f(c)\) is the absolute maximum of \(f\) on \(I\).
  • If \(f\) has a relative minimum at \(x = c\), then \(f(c)\) is the absolute minimum of \(f\) on \(I\).

You can only use this theorem if all three conditions hold: \(f\) is continuous on \(I\), \(f\) has exactly one critical number in \(I\), and \(f\) has a relative extremum at that critical number.

In plain words: if the graph has no breaks and turns around in only one place, and that place is a valley, then the graph can never get lower anywhere else, so the valley floor is the lowest point. The same is true for a single hilltop and the highest point.

Here is why it works for a relative minimum at \(c\). Just to the right of \(c\) the graph goes up. If it ever came back down below \(f(c)\), it would have to turn around somewhere, and the turning point would be a second critical number. There is only one, so the graph can never get lower than \(f(c)\) on the right. The same argument works on the left.

To decide whether the one critical number is a relative max or a relative min, use either test from Chapter 5. The first derivative test: if \(f'\) changes from positive to negative at \(c\), there is a relative maximum; if it changes from negative to positive, a relative minimum. The second derivative test: if \(f'(c) = 0\) and \(f''(c) \lt 0\), there is a relative maximum; if \(f'(c) = 0\) and \(f''(c) \gt 0\), a relative minimum.

In plain words: a hilltop is where the graph switches from going up to going down, and a valley is where it switches from going down to going up. With the second derivative, a graph that bends downward (\(f'' \lt 0\)) at a flat spot is at a hilltop, and one that bends upward (\(f'' \gt 0\)) is at a valley.

How to find absolute extrema on an interval that is not closed
  1. Check that \(f\) is continuous on the interval \(I\).
  2. Find all critical numbers of \(f\) in \(I\), and count them.
  3. If there is exactly one, decide with the first or second derivative test whether it is a relative max or a relative min, then quote the critical point theorem to call it absolute.
  4. For the other kind of extremum, look at what \(f(x)\) does near the ends of \(I\), that is, as \(x\) approaches an open endpoint, or as \(x \to \infty\). If \(f\) grows without bound, there is no absolute maximum. If \(f\) drops without bound, there is no absolute minimum. If \(f\) creeps toward a number it never reaches, that number is not attained, so there is no extremum of that kind either (see Problems 23 and 28).
  5. If there are two or more critical numbers, the theorem does not apply. Evaluate \(f\) at each critical number. Then compare those values with what \(f\) does near the ends of the interval (see Problem 27).
Worked example 6: one critical number, second derivative test

Find the absolute extrema of \(f(x) = x + \dfrac{9}{x}\) on \((0, \infty)\), or explain why they do not exist.

How to spot this type: the interval \((0, \infty)\) has no endpoints to plug in, and the phrase "or explain why they do not exist" warns you that one of them may be missing. Use the critical point theorem, then look at the ends of the interval.

  1. Check continuity. \(f\) is a sum of \(x\) and \(\tfrac{9}{x}\), and the only trouble spot for \(\tfrac{9}{x}\) is \(x = 0\), which is not in \((0, \infty)\). So \(f\) is continuous on \((0, \infty)\).
  2. Differentiate. Write \(\tfrac{9}{x} = 9x^{-1}\) and use the power rule. \[\begin{aligned} f'(x) &= 1 - 9x^{-2} \\ &= 1 - \frac{9}{x^2} \\ &= \frac{x^2 - 9}{x^2}. \end{aligned}\]
  3. Find the critical numbers in \((0, \infty)\). The numerator is zero when \(x^2 = 9\), so \(x = 3\) or \(x = -3\). The number \(-3\) is not in the interval, so we throw it out. The denominator is zero only at \(x = 0\), which is not in the interval. So \(x = 3\) is the only critical number in \((0, \infty)\).
  4. Use the second derivative test at \(x = 3\). Differentiate \(f'(x) = 1 - 9x^{-2}\) with the power rule. The 1 has derivative 0, and \(-9 \cdot (-2) = 18\). \[f''(x) = 0 - 9 \cdot (-2)x^{-3} = 18x^{-3} = \frac{18}{x^3}, \qquad f''(3) = \frac{18}{27} = \frac{2}{3} \gt 0.\] Since \(f'(3) = 0\) and \(f''(3) \gt 0\), \(f\) has a relative minimum at \(x = 3\).
  5. Apply the critical point theorem. \(f\) is continuous on \((0, \infty)\) with exactly one critical number there, and it is a relative minimum, so it is the absolute minimum. \[f(3) = 3 + \frac{9}{3} = 3 + 3 = 6.\]
  6. Show there is no absolute maximum. For \(x \gt 0\), both terms are positive, so \(f(x) \gt x\). That means \(f(x)\) is larger than any number you name once \(x\) is large enough. For example, \(f(100) = 100.09\) and \(f(1000) = 1000.009\). So \(f\) has no largest value. (It also blows up as \(x \to 0^+\), because \(\tfrac{9}{x} \to \infty\).)

Answer: The absolute minimum value is 6, attained at \(x = 3\). There is no absolute maximum.

Worked example 7: one critical number, first derivative test

Find the absolute extrema of \(f(x) = \dfrac{\ln x}{x}\) on \((0, \infty)\), or explain why they do not exist.

How to spot this type: again an interval with no endpoints and the words "or explain why they do not exist", so use the critical point theorem. The quotient \(\tfrac{\ln x}{x}\) has a messy second derivative, so a sign chart for the first derivative test is quicker.

  1. Check continuity. \(\ln x\) and \(x\) are continuous for \(x \gt 0\), and the denominator \(x\) is never zero there, so \(f\) is continuous on \((0, \infty)\).
  2. Differentiate with the quotient rule. Let \(u = \ln x\) and \(v = x\), so \(u' = \tfrac{1}{x}\) and \(v' = 1\). \[\begin{aligned} f'(x) &= \frac{u'v - uv'}{v^2} = \frac{\tfrac{1}{x} \cdot x - \ln x \cdot 1}{x^2} \\ &= \frac{1 - \ln x}{x^2}. \end{aligned}\]
  3. Find the critical numbers. The numerator is zero when \(\ln x = 1\), so \(x = e\). The denominator \(x^2\) is zero only at \(x = 0\), which is not in the domain. So \(x = e\) is the only critical number.
  4. Use the first derivative test. The denominator \(x^2\) is always positive, so the sign of \(f'\) is the sign of \(1 - \ln x\). Test one number on each side of \(e\).
    IntervalTest value\(1 - \ln x\)Sign of \(f'\)\(f\) is
    \((0, e)\)\(x = 1\)\(1 - 0 = 1\)\(+\)increasing
    \((e, \infty)\)\(x = e^2\)\(1 - 2 = -1\)\(-\)decreasing
    Because \(f'\) changes from positive to negative at \(x = e\), \(f\) has a relative maximum there.
  5. Apply the critical point theorem. \(f\) is continuous on \((0, \infty)\) and \(x = e\) is its only critical number, so the relative maximum is the absolute maximum. \[f(e) = \frac{\ln e}{e} = \frac{1}{e}.\]
  6. Show there is no absolute minimum. As \(x \to 0^+\), \(\ln x \to -\infty\) while \(\tfrac{1}{x} \to \infty\), so \(f(x) = \ln x \cdot \tfrac{1}{x} \to -\infty\). For example, \(f\left(\tfrac{1}{e}\right) = \dfrac{-1}{1/e} = -e\) and \(f\left(\tfrac{1}{e^2}\right) = \dfrac{-2}{1/e^2} = -2e^2\). The values drop below every number, so there is no smallest value.

Answer: The absolute maximum value is \(\dfrac{1}{e}\), attained at \(x = e\). There is no absolute minimum.

What to write on the exam. For an interval that is not closed, the grader wants the theorem named and its conditions checked, in a sentence like: "\(f\) is continuous on \((0, \infty)\) and \(x = e\) is its only critical number there. Since \(f'\) changes from positive to negative at \(x = e\), \(f\) has a relative maximum at \(x = e\), so by the critical point theorem \(f(e) = \tfrac{1}{e}\) is the absolute maximum on \((0, \infty)\)." To say an extremum does not exist, give the limit that shows it: "As \(x \to 0^+\), \(f(x) \to -\infty\), so there is no absolute minimum."

Average cost

If \(C(x)\) is the total cost of making \(x\) units, the average cost per unit is \(\overline{C}(x) = \dfrac{C(x)}{x}\). Minimizing average cost is an absolute minimum problem for \(\overline{C}\). Divide each term of \(C(x)\) by \(x\) first, then differentiate. If the production level is restricted to a closed interval such as \(10 \le x \le 50\), use the closed interval method. If it is only required that \(x \gt 0\), use the critical point theorem.

A useful check comes from the quotient rule, with \(u = C(x)\) and \(v = x\): \[\overline{C}'(x) = \frac{C'(x) \cdot x - C(x) \cdot 1}{x^2} = \frac{xC'(x) - C(x)}{x^2}.\] This is zero exactly when \(xC'(x) = C(x)\), that is, when \(C'(x) = \dfrac{C(x)}{x}\). So at the production level with the lowest average cost, the marginal cost \(C'(x)\) equals the average cost.

In plain words: average cost is the total cost shared equally among the units made. The cheapest level per unit is where the cost of making one more unit equals the average cost so far.

Common mistake. Forgetting the endpoints. On a closed interval, the absolute extrema are often at an endpoint (as in Examples 2 and 3), and a solution that only tests critical numbers loses points.
Common mistake. Answering with only the \(x\) or only the value. "Absolute maximum at \(x = -1\)" does not say what the maximum is. Give the value and every \(x\) where it is attained.
Common mistake. Calling a relative extremum "absolute" on an open interval without quoting the critical point theorem, or quoting it when there are two or more critical numbers in the interval. Count the critical numbers in the interval first.
Common mistake. Using the extreme value theorem on \((0, \infty)\) or on an open interval to claim that a maximum must exist. The theorem only covers continuous functions on \([a, b]\).
Common mistake. Trying to solve \(e^{-x/2} = 0\) or dividing an equation by \(\ln x\) without care. An exponential is never zero, so drop that factor. When you divide by an expression, check separately whether that expression can be zero.
If you get stuck
  • Look only at the interval first. Square brackets on both ends, like \([a, b]\), mean the value table. A parenthesis or an \(\infty\) means the critical point theorem plus a look at what \(f\) does near the ends.
  • If you cannot factor \(f'\), pull out the common factor first. It might be a number, a power of \(x\), or an exponential like \(e^{-x}\). Then factor what is left.
  • If \(f'\) has fractional or negative powers, rewrite it with positive exponents as one fraction. The top equal to zero gives \(f' = 0\), and the bottom equal to zero gives the places where \(f'\) does not exist.
  • Make a table with three columns: \(x\), why it is a candidate (endpoint or critical number), and \(f(x)\). Cross out, in writing, every critical number that is outside the interval.
  • If two values in the table are hard to compare, subtract them and decide whether the difference is positive, or divide them and compare with 1. Use \(2 \lt e \lt 3\), \(3 \lt \pi \lt 3.2\), and \(1.4 \lt \sqrt{2} \lt 1.5\).
  • To decide whether an open end gives an extremum, plug in a very large \(x\) or an \(x\) very close to the open endpoint, and ask whether \(f\) blows up, drops forever, or creeps toward a number it never reaches.
Quick check
Can the absolute maximum on a closed interval happen at a number where \(f'(x) \ne 0\)? Give an example.

Yes, at an endpoint: \(f(x) = x\) on \([0, 1]\) has absolute maximum 1 at \(x = 1\), where \(f'(1) = 1\).

Can the absolute maximum value and the absolute minimum value on an interval be equal?

Yes, but only when \(f\) is constant there: \(f(x) = 2\) on \([0, 5]\) has maximum and minimum both equal to 2, attained at every \(x\).

Is every relative maximum also an absolute maximum? Give an example.

No. In the first graph on this page, \((1, 5)\) is a relative maximum, but \(f(5) = 21\) is larger.

Does \(f(x) = \tfrac{1}{x}\) have an absolute minimum on \([1, 4]\)?

Yes. It is continuous on the closed interval \([1, 4]\), because \(x = 0\) is outside it, and \(f'(x) = -\tfrac{1}{x^2} \lt 0\), so the minimum is \(f(4) = \tfrac{1}{4}\) at the right endpoint.

A continuous function on \((0, \infty)\) has two critical numbers. Can you use the critical point theorem?

No. The theorem needs exactly one critical number, so you must compare the values at both critical numbers with what \(f\) does near 0 and as \(x \to \infty\).

What to have memorized
  • \(f(c)\) is the absolute maximum on \(S\) if \(f(c) \ge f(x)\) for every \(x\) in \(S\), and the absolute minimum if \(f(c) \le f(x)\) for every \(x\) in \(S\). There is at most one absolute max value, but it can be attained at several \(x\).
  • The extreme value theorem: a continuous function on a closed, bounded interval \([a, b]\) attains an absolute maximum and an absolute minimum. All three conditions (continuous, closed, bounded) are needed.
  • A critical number is a number \(c\) in the domain of \(f\) where \(f'(c) = 0\) or \(f'(c)\) does not exist.
  • The closed interval method: critical numbers inside \((a, b)\) plus both endpoints go in a value table, and the largest and smallest values win.
  • The critical point theorem: if \(f\) is continuous on \(I\) with exactly one critical number \(c\) in \(I\), a relative max at \(c\) is the absolute max on \(I\), and a relative min at \(c\) is the absolute min on \(I\).
  • To show no absolute max or min exists, give a limit: the function goes to \(\infty\) or \(-\infty\) near an end of the interval, or it approaches a value it never reaches.
  • Average cost is \(\overline{C}(x) = \dfrac{C(x)}{x}\), and at its minimum the marginal cost equals the average cost.

Words that change the method. "Absolute" or "global" means compare with every point of the interval, while "relative" or "local" means compare only with nearby points. Problem 2
For which of these does the extreme value theorem guarantee both an absolute maximum and an absolute minimum? Give the reason for each. (a) \(f(x) = \dfrac{1}{x - 2}\) on \([0, 3]\). (b) \(g(x) = x^2\) on \((0, 3]\). (c) \(h(x) = \sqrt{x}\) on \([0, 9]\).
Show full solution
  1. Recall the conditions. The theorem needs a continuous function on a closed and bounded interval \([a, b]\).
  2. Check (a). The interval \([0, 3]\) is closed and bounded, but \(f\) is undefined at \(x = 2\), which lies inside \([0, 3]\), so \(f\) is not continuous there. The theorem does not apply.   3. Check (b). \(g(x) = x^2\) is continuous, but \((0, 3]\) is not closed because 0 is left out. The theorem does not apply. (Here \(g\) does have an absolute maximum, \(g(3) = 9\), but no absolute minimum, since \(x^2\) gets close to 0 without reaching it.)

Problem 3
Find all critical numbers of \(f(x) = x^3 - 27x\). Which of them would you use in the closed interval method on \([0, 5]\)?
Show full solution
  1. Differentiate with the power rule and factor. \[\begin{aligned} f'(x) &= 3x^2 - 27 \\ &= 3(x^2 - 9) \\ &= 3(x - 3)(x + 3). \end{aligned}\]
  2. Solve \(f'(x) = 0\). The derivative of a polynomial exists everywhere, so these are all the critical numbers. \[3(x - 3)(x + 3) = 0 \quad \text{gives} \quad x = 3 \ \text{or} \ x = -3.\]
  3. Keep only the critical numbers inside \((0, 5)\). The number 3 is inside, and \(-3\) is not, so \(-3\) is thrown out.

Answer: The critical numbers are \(x = 3\) and \(x = -3\). Only \(x = 3\) is used on \([0, 5]\).

Problem 6
Use the critical point theorem to find the absolute minimum of \(f(x) = x^2 - 8x + 3\) on \((-\infty, \infty)\). Does \(f\) have an absolute maximum?
Show full solution
  1. Check continuity. \(f\) is a polynomial, so it is continuous on \((-\infty, \infty)\).
  2. Find the critical numbers. \[f'(x) = 2x - 8 = 0 \quad \text{gives} \quad x = 4.\] The derivative exists everywhere, so \(x = 4\) is the only critical number.
  3. Use the second derivative test. \(f''(x) = 2\), so \(f''(4) = 2 \gt 0\). Since \(f'(4) = 0\) and \(f''(4) \gt 0\), there is a relative minimum at \(x = 4\).

  5. Decide about a maximum. As \(x \to \infty\), the \(x^2\) term grows much faster than \(-8x + 3\), so \(f(x) \to \infty\). For example, \(f(100) = 10000 - 800 + 3 = 9203\). The values grow without bound, so there is no absolute maximum.

Problem 11
The total cost, in dollars, of producing \(x\) units of a product is \(C(x) = 2x^2 + 50x + 800\). The factory can make between 5 and 40 units per day. Find the production level in \([5, 40]\) that minimizes the average cost per unit, and find that minimum average cost.

Problem 13

Problem 14
Find the absolute maximum and minimum values of \(f(x) = x^{1/3}(x - 4)\) on \([-1, 8]\).

Show full solution
  1. Check continuity. The cube root \(x^{1/3}\) is defined and continuous for every real number, so \(f\) is continuous on \([-1, 8]\) and both extrema exist.

Problem 15
Find the absolute extrema of \(f(x) = x^2 - 8\ln x\) on \((0, \infty)\), or explain why they do not exist.
Hint
The interval has no endpoints, so count the critical numbers inside \((0, \infty)\). Then think about what \(-8\ln x\) does as \(x \to 0^+\).
Show full solution
  1. Check continuity. \(x^2\) is continuous everywhere and \(\ln x\) is continuous for \(x \gt 0\), so \(f\) is continuous on \((0, \infty)\). The interval is not closed, so the closed interval method does not apply. We will use the critical point theorem.
  2. Differentiate and write as one fraction. \[\begin{aligned} f'(x) &= 2x - \frac{8}{x} \\ &= \frac{2x^2 - 8}{x} \\ &= \frac{2(x - 2)(x + 2)}{x}. \end{aligned}\]
  3. Find the critical numbers in \((0, \infty)\). The numerator is zero at \(x = 2\) and \(x = -2\). The number \(-2\) is not in the interval. The denominator is zero only at \(x = 0\), which is not in the domain. So \(x = 2\) is the only critical number.
  4. Use the second derivative test. From \(f'(x) = 2x - 8x^{-1}\), \[f''(x) = 2 + 8x^{-2} = 2 + \frac{8}{x^2}, \qquad f''(2) = 2 + \frac{8}{4} = 4 \gt 0.\] Since \(f'(2) = 0\) and \(f''(2) \gt 0\), \(f\) has a relative minimum at \(x = 2\).
  5. Apply the critical point theorem. \(f\) is continuous on \((0, \infty)\) with exactly one critical number there, and it is a relative minimum, so it is the absolute minimum. \[f(2) = 2^2 - 8\ln 2 = 4 - 8\ln 2.\]
  6. Show there is no absolute maximum. As \(x \to 0^+\), \(\ln x \to -\infty\), so \(-8\ln x \to \infty\), while \(x^2 \to 0\). So \(f(x) \to \infty\). For example, since \(\ln\left(\tfrac{1}{e^2}\right) = \ln\left(e^{-2}\right) = -2\), \(f\left(\tfrac{1}{e^2}\right) = \left(\tfrac{1}{e^2}\right)^2 - 8(-2) = \tfrac{1}{e^4} + 16\), and \(f\left(\tfrac{1}{e^{10}}\right) = \tfrac{1}{e^{20}} + 80\). The values grow without bound, so there is no largest one.

Answer: The absolute minimum value is \(4 - 8\ln 2\), attained at \(x = 2\). There is no absolute maximum.

Where students lose points: Calling \(f(2)\) the absolute minimum without saying that \(x = 2\) is the only critical number and naming the critical point theorem, or forgetting to explain why there is no absolute maximum.

Part (a) is on \((0, \infty)\), so use the critical point theorem. For part (b), write out what the sentence "2 is the smallest value of \(f\)" says as an inequality.
Show full solution
  1. Check continuity. \(\sqrt{x}\) and \(\ln x\) are continuous for \(x \gt 0\), so \(f\) is continuous on \((0, \infty)\). This interval is not closed, so we use the critical point theorem.
  2. Differentiate. Write \(2\sqrt{x} = 2x^{1/2}\), so its derivative is \(2 \cdot \tfrac{1}{2}x^{-1/2} = \tfrac{1}{\sqrt{x}}\). \[f'(x) = \frac{1}{\sqrt{x}} - \frac{1}{x}.\]
  3. Combine into one fraction with denominator \(x\). Since \(\tfrac{1}{\sqrt{x}} = \tfrac{\sqrt{x}}{\sqrt{x}\sqrt{x}} = \tfrac{\sqrt{x}}{x}\), \[f'(x) = \frac{\sqrt{x}}{x} - \frac{1}{x} = \frac{\sqrt{x} - 1}{x}.\]
  4. Find the critical numbers. The numerator is zero when \(\sqrt{x} = 1\), so \(x = 1\). The denominator is zero only at \(x = 0\), which is not in the domain. So \(x = 1\) is the only critical number in \((0, \infty)\).
  5. Use the first derivative test. For \(x \gt 0\) the denominator is positive, so the sign of \(f'\) is the sign of \(\sqrt{x} - 1\).
    IntervalTest value\(\sqrt{x} - 1\)Sign of \(f'\)\(f\) is
    \((0, 1)\)\(x = \tfrac{1}{4}\)\(\tfrac{1}{2} - 1 = -\tfrac{1}{2}\)\(-\)decreasing
    \((1, \infty)\)\(x = 4\)\(2 - 1 = 1\)\(+\)increasing
    Because \(f'\) changes from negative to positive at \(x = 1\), \(f\) has a relative minimum at \(x = 1\).
  6. Apply the critical point theorem. \(f\) is continuous on \((0, \infty)\) and \(x = 1\) is its only critical number there, so the relative minimum is the absolute minimum. \[f(1) = 2\sqrt{1} - \ln 1 = 2 - 0 = 2.\]
  7. Show there is no absolute maximum. As \(x \to 0^+\), \(\ln x \to -\infty\), so \(-\ln x \to \infty\), while \(2\sqrt{x} \to 0\). So \(f(x) \to \infty\). For example, \(f\left(\tfrac{1}{e^{10}}\right) = \tfrac{2}{e^5} + 10 \gt 10\). The values grow without bound, so there is no largest value.
  8. Part (b). Part (a) says 2 is the smallest value of \(f\) on \((0, \infty)\), so \(f(x) \ge 2\) for every \(x \gt 0\). Write that out and rearrange. \[\begin{aligned} 2\sqrt{x} - \ln x &\ge 2 \\ 2\sqrt{x} - 2 &\ge \ln x. \end{aligned}\]

Answer: (a) The absolute minimum value is 2, attained at \(x = 1\). There is no absolute maximum, because \(f(x) \to \infty\) as \(x \to 0^+\). (b) Since \(f(x) \ge 2\) for all \(x \gt 0\), \(2\sqrt{x} - \ln x \ge 2\), which rearranges to \(\ln x \le 2\sqrt{x} - 2\).

Where students lose points: In part (a), skipping the reason that the relative minimum is absolute. In part (b), rearranging without first stating that \(f(x) \ge 2\) for every \(x \gt 0\).

Problem 21
A workshop's total cost, in dollars, to make \(x\) chairs per day is \(C(x) = 2x^2 + 30x + 1800\). (a) If any positive number of chairs per day is allowed, how many chairs per day minimize the average cost per chair? Explain why your answer gives the smallest possible average cost, and find that average cost. (b) The workshop can make at most 20 chairs per day. Now how many chairs per day minimize the average cost, and what is the minimum average cost?
Hint
In part (a) the domain is \((0, \infty)\). In part (b), check whether the critical number from part (a) is still allowed, and look at the sign of \(\overline{C}'\) on the new domain.
Show full solution
  1. Define the variables. Let \(x\) be the number of chairs made per day and \(\overline{C}(x)\) the average cost in dollars per chair. Divide each term of \(C(x)\) by \(x\). \[\overline{C}(x) = \frac{2x^2 + 30x + 1800}{x} = 2x + 30 + \frac{1800}{x}.\] In part (a) the domain is \(x \gt 0\), that is, \((0, \infty)\). \(\overline{C}\) is continuous there.
  2. Differentiate. Write \(\tfrac{1800}{x} = 1800x^{-1}\). \[\begin{aligned} \overline{C}'(x) &= 2 - 1800x^{-2} = 2 - \frac{1800}{x^2} \\ &= \frac{2x^2 - 1800}{x^2} = \frac{2(x^2 - 900)}{x^2}. \end{aligned}\]
  3. Find the critical numbers in \((0, \infty)\). The numerator is zero when \(x^2 = 900\), so \(x = 30\) or \(x = -30\). The number \(-30\) is not in the domain, and the denominator is zero only at \(x = 0\), also not in the domain. So \(x = 30\) is the only critical number.
  4. Use the second derivative test. From \(\overline{C}'(x) = 2 - 1800x^{-2}\), \[\overline{C}''(x) = 3600x^{-3} = \frac{3600}{x^3}, \qquad \overline{C}''(30) = \frac{3600}{30^3} = \frac{3600}{27000} = \frac{36}{270} = \frac{2}{15} \gt 0.\] So \(\overline{C}\) has a relative minimum at \(x = 30\).
  5. Apply the critical point theorem. \(\overline{C}\) is continuous on \((0, \infty)\) and \(x = 30\) is its only critical number there, so the relative minimum is the absolute minimum. \[\overline{C}(30) = 2(30) + 30 + \frac{1800}{30} = 60 + 30 + 60 = 150.\] As a check, the marginal cost is \(C'(x) = 4x + 30\), and \(C'(30) = 120 + 30 = 150\) equals the average cost there.
  6. Part (b): the domain is now \((0, 20]\), and the critical number 30 is not in it. For \(0 \lt x \le 20\) we have \(x^2 \le 400 \lt 900\), so the numerator \(2(x^2 - 900)\) is negative and \(\overline{C}'(x) \lt 0\). That means \(\overline{C}\) is decreasing on all of \((0, 20]\), so its smallest value is at the right end, \(x = 20\). (Near \(x = 0\), \(\tfrac{1800}{x} \to \infty\), so small production levels are very expensive per chair.) \[\overline{C}(20) = 2(20) + 30 + \frac{1800}{20} = 40 + 30 + 90 = 160.\]

Answer: (a) 30 chairs per day, with a minimum average cost of \$150 per chair. It is the smallest possible because \(x = 30\) is the only critical number on \((0, \infty)\) and \(\overline{C}''(30) \gt 0\), so by the critical point theorem it is the absolute minimum. (b) 20 chairs per day, with a minimum average cost of \$160 per chair, because \(\overline{C}\) is decreasing on \((0, 20]\).

Where students lose points: In part (b), answering 30 chairs again even though 30 is above the cap, or naming \(x = 20\) without explaining that \(\overline{C}\) is decreasing on \((0, 20]\).

Problem 22
Decide whether each statement is true or false. If it is true, say which theorem makes it true. If it is false, give a specific function and interval where it fails. (a) If \(f\) is continuous on \([a, b]\), then the absolute maximum of \(f\) on \([a, b]\) happens at a number where \(f'(x) = 0\). (b) Every continuous function on \((0, 1)\) has an absolute maximum on \((0, 1)\). (c) A function can have two different absolute maximum values on the same interval. (d) If \(f\) is continuous on \((0, \infty)\), \(c\) is its only critical number there, \(f'(c) = 0\), and \(f''(c) \gt 0\), then \(f(c)\) is the absolute minimum of \(f\) on \((0, \infty)\).
Hint
For each false statement, look for one simple function, such as \(x\) or \(x^2\), on an interval where the statement breaks.
Show full solution
  1. Statement (a) is false, because the maximum can be at an endpoint. Take \(f(x) = x^2\) on \([1, 3]\). Here \(f'(x) = 2x\), which is positive on the whole interval, so \(f\) is increasing and its absolute maximum is \(f(3) = 9\) at the right endpoint. But \(f'(3) = 2 \cdot 3 = 6\), not 0.
  2. Statement (b) is false, because the extreme value theorem needs a closed interval. Take \(f(x) = x\) on \((0, 1)\). It is continuous, and its values get close to 1 but never reach 1. For any \(x\) in \((0, 1)\), the number \(\tfrac{x + 1}{2}\) is also in \((0, 1)\) and is larger than \(x\), so \(f\) has no largest value.
  3. Statement (c) is false. Suppose \(M_1\) and \(M_2\) were both absolute maximum values on the same interval. Since \(M_1\) is the absolute maximum and \(M_2\) is a value of \(f\), \(M_1 \ge M_2\). For the same reason \(M_2 \ge M_1\). So \(M_1 = M_2\). What can happen is that the one maximum value is attained at several \(x\). For example, \(\cos x\) on \([0, 2\pi]\) has maximum value 1, attained at both \(x = 0\) and \(x = 2\pi\), since \(\cos 0 = \cos 2\pi = 1\).
  4. Statement (d) is true. Since \(f'(c) = 0\) and \(f''(c) \gt 0\), the second derivative test says \(f\) has a relative minimum at \(c\). Then \(f\) is continuous on \((0, \infty)\) with exactly one critical number there, and it is a relative minimum, so the critical point theorem says \(f(c)\) is the absolute minimum on \((0, \infty)\).

Answer: (a) False, for example \(x^2\) on \([1, 3]\) has its maximum at \(x = 3\) where \(f' = 6\). (b) False, for example \(x\) on \((0, 1)\) has no maximum. (c) False, there is only one maximum value, though it can be attained at several \(x\). (d) True, by the second derivative test and the critical point theorem.

Problem 23
The graph of \(f(x) = x^2 - 2x\) on the half-open interval \((-1, 2]\) is shown below. The left end \(x = -1\) is not part of the interval, so the point \((-1, 3)\) is drawn as an open dot. Ask whether the left end of the graph is really part of the graph. A height that the curve only approaches is never attained.
Show full solution
  1. Rewrite \(f\) by completing the square, so the heights are easy to compare. \[f(x) = x^2 - 2x = (x^2 - 2x + 1) - 1 = (x - 1)^2 - 1.\]

  3. Look at the highest heights. The included right end has \(f(2) = 4 - 4 = 0\). The open dot has height \(f(-1) = 1 + 2 = 3\), but \(x = -1\) is not in the interval, so that height is never attained.
  4. Show that \(f(x) \lt 3\) for every \(x\) in the interval. If \(-1 \lt x \le 2\), then subtracting 1 gives \(-2 \lt x - 1 \le 1\). So the distance from \(x - 1\) to 0 is less than 2, and \((x - 1)^2 \lt 4\). Then \[f(x) = (x - 1)^2 - 1 \lt 4 - 1 = 3.\]

If instead \(x\) is in \([1, 2]\), then \(0 \le x - 1 \le 1\), so \(f(x) = (x - 1)^2 - 1 \le 0\), which is less than \(f\left(-\tfrac{1}{2}\right) = \tfrac{1}{4} + 1 = \tfrac{5}{4}\). Answer: The absolute minimum value is \(-1\), attained at \(x = 1\). There is no absolute maximum: \(f(x)\) approaches 3 as \(x \to -1^+\), but \(f(x) \lt 3\) for every \(x\) in \((-1, 2]\).

Problem 25

  2. Differentiate. Write \(\tfrac{k}{x} = kx^{-1}\) and use the power rule. \[f'(x) = 2x - kx^{-2} = 2x - \frac{k}{x^2}.\]

Answer: \(k = 54\). The absolute minimum value is 27, attained at \(x = 3\). It is absolute because \(x = 3\) is the only critical number in \((0, \infty)\) and \(f''(3) = 6 \gt 0\), so the critical point theorem applies.

Problem 26

Remove the absolute value bars by splitting the interval at the number where \(x^2 - 4\) changes sign. The graph has a corner there.

Problem 27
Find the absolute maximum and minimum values of \(f(x) = \dfrac{4x^2}{x^4 + 16}\), if they exist, and every \(x\) where they occur. No interval is given, so use the whole domain of \(f\). Justify your answer.
Hint
With no interval given, work on the whole real line. Factor the top of \(f'\) completely, and find what \(f\) does as \(x \to \infty\) and \(x \to -\infty\).
Show full solution
  1. Find the domain. The denominator satisfies \(x^4 + 16 \ge 16 \gt 0\), so it is never zero. The domain is all real numbers, \((-\infty, \infty)\), and \(f\) is continuous there. This interval is not closed and bounded, so the extreme value theorem does not apply.
  2. Differentiate with the quotient rule. Let \(u = 4x^2\) and \(v = x^4 + 16\), so \(u' = 8x\) and \(v' = 4x^3\). \[\begin{aligned} f'(x) &= \frac{u'v - uv'}{v^2} = \frac{8x(x^4 + 16) - 4x^2 \cdot 4x^3}{(x^4 + 16)^2} \\ &= \frac{8x^5 + 128x - 16x^5}{(x^4 + 16)^2} = \frac{128x - 8x^5}{(x^4 + 16)^2}. \end{aligned}\]

There are three critical numbers, so the critical point theorem does not apply. We compare values and look at the ends.

    IntervalTest value\(-8x(x - 2)(x + 2)\)Sign of \(f'\)\(f\) is
    \((-\infty, -2)\)\(x = -3\)\(-8(-3)(-5)(-1) = 120\)\(+\)increasing

So \(f(x) \le \tfrac{1}{2}\) for every \(x\), with equality only at \(x = \pm 2\).

Problem 28

    IntervalTest value\(3 - x\)Sign of \(f'\)\(f\) is
    \((0, 3)\)\(x = 1\)\(2\)\(+\)increasing

Answer: The absolute maximum value is \(\dfrac{27}{e^3}\), attained at \(x = 3\). There is no absolute minimum, because \(f(x) \gt 0\) for every \(x \gt 0\) while \(f(x) \to 0\) as \(x \to 0^+\) and as \(x \to \infty\).

Problem 29
A wire \(4 + \pi\) meters long is cut into two pieces. One piece is bent into a circle and the other into a square. It is allowed to use all of the wire for just one of the shapes. Where should the cut be made so that the total area enclosed is as small as possible? Where should it be made so that the total area is as large as possible? Give exact answers.
Hint
Let \(x\) be the length bent into the circle. Write each area in terms of \(x\), and remember that \(x = 0\) and \(x = 4 + \pi\) are both allowed, so the domain is a closed interval.
Show full solution
  1. Define the variables and the domain. Let \(x\) be the length of wire, in meters, bent into the circle. The rest, \(4 + \pi - x\) meters, becomes the square. Using all the wire for one shape is allowed, so \(0 \le x \le 4 + \pi\).
  2. Write the circle's area. The circumference is \(2\pi r = x\), so \(r = \tfrac{x}{2\pi}\). \[\text{circle area} = \pi r^2 = \pi \cdot \frac{x^2}{4\pi^2} = \frac{x^2}{4\pi}.\]
  3. Write the square's area. The perimeter is \(4 + \pi - x\), so each side is \(\tfrac{4 + \pi - x}{4}\). \[\text{square area} = \left(\frac{4 + \pi - x}{4}\right)^2 = \frac{(4 + \pi - x)^2}{16}.\]
  4. Write the total area and state the method. \[A(x) = \frac{x^2}{4\pi} + \frac{(4 + \pi - x)^2}{16}, \qquad 0 \le x \le 4 + \pi.\] \(A\) is a polynomial in \(x\), so it is continuous on this closed interval and the closed interval method applies.
  5. Differentiate. For the second term use the chain rule: the inside \(4 + \pi - x\) has derivative \(-1\). \[A'(x) = \frac{2x}{4\pi} + \frac{2(4 + \pi - x)(-1)}{16} = \frac{x}{2\pi} - \frac{4 + \pi - x}{8}.\]
  6. Solve \(A'(x) = 0\). Multiply both sides by \(8\pi\) to clear the fractions. \[\begin{aligned} 4x - \pi(4 + \pi - x) &= 0 \\ 4x - 4\pi - \pi^2 + \pi x &= 0 \\ (4 + \pi)x &= 4\pi + \pi^2 = \pi(4 + \pi) \\ x &= \pi. \end{aligned}\] Since \(0 \lt \pi \lt 4 + \pi\), the critical number \(x = \pi\) is inside the interval.
  7. Evaluate \(A\) at the critical number and both endpoints. At \(x = \pi\), the square gets \(4 + \pi - \pi = 4\) meters. \[\begin{aligned} A(0) &= 0 + \frac{(4 + \pi)^2}{16} = \frac{(4 + \pi)^2}{16}, \\ A(\pi) &= \frac{\pi^2}{4\pi} + \frac{4^2}{16} = \frac{\pi}{4} + 1 = \frac{4 + \pi}{4}, \\ A(4 + \pi) &= \frac{(4 + \pi)^2}{4\pi} + 0 = \frac{(4 + \pi)^2}{4\pi}. \end{aligned}\]
  8. Find the smallest without a calculator. Let \(L = 4 + \pi\). Then \(A(\pi) = \tfrac{L}{4}\), \(A(0) = \tfrac{L}{4} \cdot \tfrac{L}{4}\), and \(A(L) = \tfrac{L}{4} \cdot \tfrac{L}{\pi}\). Since \(L\) is bigger than both 4 and \(\pi\), the factors \(\tfrac{L}{4}\) and \(\tfrac{L}{\pi}\) are bigger than 1. So both endpoint values are bigger than \(\tfrac{L}{4}\), and \(A(\pi)\) is the smallest.
  9. Find the largest. Compare \(A(0) = \tfrac{L^2}{16}\) with \(A(L) = \tfrac{L^2}{4\pi}\). They have the same top. Since \(\pi \lt 4\), we have \(4\pi \lt 16\), and dividing by the smaller number gives the bigger result. So \(A(L)\) is the largest.

Answer: For the smallest total area, cut so that \(\pi\) meters go into the circle and 4 meters into the square (a square of side 1 m). The minimum area is \(1 + \dfrac{\pi}{4}\) square meters. For the largest total area, do not cut at all: bend all \(4 + \pi\) meters into the circle, for an area of \(\dfrac{(4 + \pi)^2}{4\pi}\) square meters.
