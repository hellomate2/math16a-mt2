Past Berkeley exam problems: derivatives, extrema, sketching

The 18 problems in this unit are real questions from past UC Berkeley Math 16A midterms and finals, written by other instructors between 1995 and 2017. Each one is restated in new words, but the math is unchanged: the same function, the same numbers, and the same question. The small tag at the start of each problem names the instructor, the semester, and the exam it came from. These instructors used different textbooks and wrote their exams in their own style, so the wording will not match Prof. Gomez's exams exactly. The skills are the same ones he tests: derivative rules, implicit differentiation, L'Hospital's rule, relative and absolute extrema, concavity, and curve sketching.

The problems are split into three sets by difficulty. Set 1 has short, one-idea questions. Set 2 has standard exam questions. Set 3 has the hardest ones: corners, cusps, asymptotes, and questions that ask you to explain why.

How to use these problems

  1. Give yourself about 12 minutes per problem, written out on paper with no calculator and no notes. That is roughly the pace of a 5-question, 60-minute midterm.
  2. Write every step and every justification sentence, as if a grader were reading it. A correct number with no reasoning does not earn full credit.
  3. Only open the solution after the timer ends. If you went over 12 minutes, note which step slowed you down and redo that kind of problem from the matching unit.
Definitions differ between instructors. Prof. Gomez defines an inflection point as a point \((c, f(c))\) where \(f\) is continuous and the concavity changes. At least one of the other instructors appears to have also required the derivative to exist there. Where that changes an answer, the solution here follows Prof. Gomez's definition and says what the original solution listed.

Problem 1
Paulin, Fall 2017, Midterm 2 Find the derivative of each function. You do not have to simplify.
(a) \(f(x) = x e^{x^2}\)
(b) \(g(x) = \ln\left(\dfrac{e^x}{\sqrt{x^2 - 1}}\right)\)
Show full solution
  1. (a) The function is a product of \(x\) and \(e^{x^2}\), so use the product rule \((uv)' = u'v + uv'\). Name the pieces first. Let \(u = x\) and \(v = e^{x^2}\). Then \(u' = 1\). For \(v'\) use the chain rule for \(e^{g(x)}\), whose derivative is \(e^{g(x)} g'(x)\), with \(g(x) = x^2\) and \(g'(x) = 2x\): \[v' = e^{x^2}\cdot 2x = 2x e^{x^2}.\]
  2. Put the pieces into the product rule and factor out the common exponential. \[\begin{aligned} f'(x) &= u'v + uv'\\ &= 1\cdot e^{x^2} + x\cdot 2x e^{x^2}\\ &= e^{x^2} + 2x^2 e^{x^2}\\ &= \left(1 + 2x^2\right)e^{x^2}. \end{aligned}\]
  3. (b) Before differentiating, use the log rules \(\ln\frac{A}{B} = \ln A - \ln B\) and \(\ln A^k = k\ln A\) to break the logarithm apart. This is allowed because on the domain of \(g\) (where \(x^2 - 1 \gt 0\)) both \(e^x\) and \(\sqrt{x^2 - 1}\) are positive. Also \(\ln e^x = x\) because \(\ln\) and \(e^x\) are inverse functions. \[\begin{aligned} g(x) &= \ln e^x - \ln\left(x^2 - 1\right)^{1/2}\\ &= x - \tfrac{1}{2}\ln\left(x^2 - 1\right). \end{aligned}\]
  4. Differentiate term by term. The derivative of \(x\) is \(1\). For \(\ln\left(x^2 - 1\right)\) use the chain rule \(\dfrac{d}{dx}\ln h(x) = \dfrac{h'(x)}{h(x)}\) with \(h(x) = x^2 - 1\) and \(h'(x) = 2x\). \[\begin{aligned} g'(x) &= 1 - \frac{1}{2}\cdot\frac{2x}{x^2 - 1}\\ &= 1 - \frac{x}{x^2 - 1}. \end{aligned}\]
  5. The problem does not ask for simplification, but combining over the common denominator \(x^2 - 1\) gives a single fraction. \[\begin{aligned} g'(x) &= \frac{x^2 - 1}{x^2 - 1} - \frac{x}{x^2 - 1}\\ &= \frac{x^2 - x - 1}{x^2 - 1}. \end{aligned}\]

Answer: (a) \(f'(x) = e^{x^2} + 2x^2 e^{x^2} = (1 + 2x^2)e^{x^2}\). (b) \(g'(x) = 1 - \dfrac{x}{x^2 - 1} = \dfrac{x^2 - x - 1}{x^2 - 1}\).

Problem 2
Coward, 2014, practice final The equation \(\sec(xy) = 5\) defines \(y\) implicitly as a function of \(x\). Find \(\dfrac{dy}{dx}\).
Show full solution
  1. Implicit differentiation means differentiating both sides of the equation with respect to \(x\), treating \(y\) as a function of \(x\), so every time \(y\) is differentiated a factor \(\frac{dy}{dx}\) appears. The right side is the constant \(5\), whose derivative is \(0\). \[\frac{d}{dx}\left[\sec(xy)\right] = \frac{d}{dx}[5] = 0.\]
  2. Differentiate the left side with the chain rule. The outside function is \(\sec u\), whose derivative is \(\sec u\tan u\), and the inside is \(u = xy\). \[\frac{d}{dx}\left[\sec(xy)\right] = \sec(xy)\tan(xy)\cdot\frac{d}{dx}[xy].\]
  3. The inside \(xy\) is a product, so use the product rule with the pieces \(x\) (derivative \(1\)) and \(y\) (derivative \(\frac{dy}{dx}\)). \[\frac{d}{dx}[xy] = 1\cdot y + x\cdot\frac{dy}{dx} = y + x\frac{dy}{dx}.\]
  4. Put the two steps together and set the result equal to \(0\). \[\sec(xy)\tan(xy)\left(y + x\frac{dy}{dx}\right) = 0.\]
  5. Check that the factor \(\sec(xy)\tan(xy)\) is never zero on this curve, so it is safe to divide by it. On the curve \(\sec(xy) = 5 \ne 0\). If \(\tan(xy)\) were \(0\), then \(\sin(xy) = 0\), so \(\cos(xy) = \pm 1\) and \(\sec(xy) = \pm 1\), which contradicts \(\sec(xy) = 5\). So \(\tan(xy) \ne 0\) too. Divide both sides by \(\sec(xy)\tan(xy)\). \[y + x\frac{dy}{dx} = 0.\]
  6. Solve for \(\frac{dy}{dx}\). Dividing by \(x\) is allowed because \(x \ne 0\) on the curve: at \(x = 0\) the equation would read \(\sec 0 = 1 = 5\), which is false. \[\begin{aligned} x\frac{dy}{dx} &= -y\\ \frac{dy}{dx} &= -\frac{y}{x}. \end{aligned}\]

Answer: \(\dfrac{dy}{dx} = -\dfrac{y}{x}\).

Problem 3
Slaman, Fall 2010, Final Evaluate each limit.
(a) \(\displaystyle\lim_{h\to 0}\frac{\ln(2 + h) - \ln 2}{h}\)
(b) \(\displaystyle\lim_{x\to 1}\frac{x^3 - x}{x - 1}\)
Show full solution
  1. (a) First plug in \(h = 0\) to see what form the limit has. The numerator becomes \(\ln 2 - \ln 2 = 0\) and the denominator becomes \(0\). This is the indeterminate form \(\frac{0}{0}\), so L'Hospital's rule applies: the limit equals the limit of the derivative of the top over the derivative of the bottom, both taken with respect to \(h\).
  2. Differentiate the top and bottom with respect to \(h\). The term \(\ln 2\) is a constant, so its derivative is \(0\). By the chain rule, \(\frac{d}{dh}\ln(2 + h) = \frac{1}{2 + h}\cdot 1\). The derivative of the bottom \(h\) is \(1\). \[\lim_{h\to 0}\frac{\ln(2 + h) - \ln 2}{h} = \lim_{h\to 0}\frac{\frac{1}{2 + h}}{1} = \frac{1}{2 + 0} = \frac{1}{2}.\]
  3. Check with a second method. The expression is the difference quotient \(\frac{f(2 + h) - f(2)}{h}\) for \(f(x) = \ln x\), so the limit is the definition of \(f'(2)\). Since \(f'(x) = \frac{1}{x}\), the limit is \(f'(2) = \frac{1}{2}\), the same answer.
  4. (b) Plug in \(x = 1\). The numerator is \(1 - 1 = 0\) and the denominator is \(1 - 1 = 0\), so this is again the form \(\frac{0}{0}\). Factor the numerator to cancel the factor that causes the zero. \[x^3 - x = x\left(x^2 - 1\right) = x(x - 1)(x + 1).\]
  5. Cancel \(x - 1\), which is allowed because \(x \ne 1\) while \(x\) approaches \(1\), and then plug in. \[\lim_{x\to 1}\frac{x(x - 1)(x + 1)}{x - 1} = \lim_{x\to 1}x(x + 1) = 1\cdot 2 = 2.\]
  6. Check with L'Hospital's rule. The derivative of the top is \(3x^2 - 1\) and the derivative of the bottom is \(1\). \[\lim_{x\to 1}\frac{3x^2 - 1}{1} = 3(1)^2 - 1 = 2.\] Both methods agree.

Answer: (a) \(\dfrac{1}{2}\). (b) \(2\).

Problem 4
Weinstein, Fall 1995, Midterm 2 The tangent line to the graph of \(g\) at \(x = 2\) has slope \(5\). Let \(f(x) = 5x^2\). You are also told that \(g(6) = 4\), \(g(2) = 6\), \(g'(12) = 8\), and \(g'(6) = 14\). Find the equation of the tangent line to the graph of \(y = f(g(x))\) at \(x = 2\).
Show full solution
  1. Name the composite function and read off what the problem gives. Let \(h(x) = f(g(x))\). The slope of the tangent line to \(g\) at \(x = 2\) is \(g'(2)\), so \(g'(2) = 5\). A tangent line needs a point and a slope, so we need \(h(2)\) and \(h'(2)\).
  2. Find the point. Use \(g(2) = 6\) and then apply \(f\). \[h(2) = f(g(2)) = f(6) = 5\cdot 6^2 = 5\cdot 36 = 180.\] The tangent line passes through \((2, 180)\).
  3. Find the slope with the chain rule \(h'(x) = f'(g(x))\cdot g'(x)\). First differentiate \(f\): \(f'(x) = 10x\). Then evaluate at \(x = 2\), putting \(g(2) = 6\) inside \(f'\). \[\begin{aligned} h'(2) &= f'(g(2))\cdot g'(2)\\ &= f'(6)\cdot 5\\ &= (10\cdot 6)\cdot 5\\ &= 300. \end{aligned}\]
  4. The values \(g(6) = 4\), \(g'(12) = 8\), and \(g'(6) = 14\) are not needed. They are there to catch the mistake of plugging the wrong number into \(g'\). In \(f'(g(2))\cdot g'(2)\), both \(g\) and \(g'\) are evaluated at \(x = 2\) itself.
  5. Write the line in point-slope form \(y - y_1 = m(x - x_1)\) and simplify. \[\begin{aligned} y - 180 &= 300(x - 2)\\ y &= 300x - 600 + 180\\ y &= 300x - 420. \end{aligned}\]

Answer: \(y = 300x - 420\).

Problem 5
Paulin, Fall 2017, practice Midterm 2 Find and classify the relative extrema of \(f(x) = x^3 - 6x^2 + 9x + 1\). Justify your answer carefully.
Show full solution
  1. Note the domain. \(f\) is a polynomial, so its domain is all real numbers and \(f'\) exists everywhere.
  2. Differentiate with the power rule and factor. \[\begin{aligned} f'(x) &= 3x^2 - 12x + 9\\ &= 3\left(x^2 - 4x + 3\right)\\ &= 3(x - 1)(x - 3). \end{aligned}\]
  3. Find the critical numbers, the numbers in the domain where \(f'(x) = 0\) or \(f'(x)\) does not exist. Here \(f'\) always exists, and \(3(x - 1)(x - 3) = 0\) gives \(x = 1\) and \(x = 3\).
  4. Make a sign chart for \(f'\) by testing one number in each interval. \[\begin{aligned} f'(0) &= 3(0 - 1)(0 - 3) = 3(-1)(-3) = 9 \gt 0,\\ f'(2) &= 3(2 - 1)(2 - 3) = 3(1)(-1) = -3 \lt 0,\\ f'(4) &= 3(4 - 1)(4 - 3) = 3(3)(1) = 9 \gt 0. \end{aligned}\]
    Interval\((-\infty, 1)\)\((1, 3)\)\((3, \infty)\)
    Sign of \(f'\)\(+\)\(-\)\(+\)
    \(f\) isincreasingdecreasingincreasing
  5. Classify with the first derivative test. Because \(f'\) changes from positive to negative at \(x = 1\), \(f\) has a relative maximum at \(x = 1\). Because \(f'\) changes from negative to positive at \(x = 3\), \(f\) has a relative minimum at \(x = 3\).
  6. Find the \(y\)-values. \[\begin{aligned} f(1) &= 1 - 6 + 9 + 1 = 5,\\ f(3) &= 27 - 54 + 27 + 1 = 1. \end{aligned}\]

Answer: relative maximum at \((1, 5)\) and relative minimum at \((3, 1)\).

Problem 6
Woodin, Fall 2012, Midterm 2 Find the minimum value of \(2a\ln a + a\) for \(a \gt 0\).
Show full solution
  1. Call the function \(f(a) = 2a\ln a + a\) with domain \(a \gt 0\). Differentiate. The term \(2a\ln a\) is a product, so use the product rule with \(u = 2a\), \(v = \ln a\), \(u' = 2\), \(v' = \frac{1}{a}\). \[\begin{aligned} f'(a) &= \left(2\ln a + 2a\cdot\frac{1}{a}\right) + 1\\ &= 2\ln a + 2 + 1\\ &= 2\ln a + 3. \end{aligned}\]
  2. Find the critical numbers. \(f'(a)\) exists for every \(a \gt 0\), so solve \(f'(a) = 0\). \[\begin{aligned} 2\ln a + 3 &= 0\\ \ln a &= -\tfrac{3}{2}\\ a &= e^{-3/2}. \end{aligned}\] This is the only critical number.
  3. Show that this critical number gives the minimum of the whole function. The second derivative is \[f''(a) = \frac{2}{a},\] which is positive for every \(a \gt 0\). So \(f\) is concave up on its entire domain. A function that is concave up on an interval and has \(f' = 0\) at a point of that interval has its absolute minimum there. (Equivalently, \(f'(a) \lt 0\) for \(0 \lt a \lt e^{-3/2}\) because \(\ln a \lt -\frac{3}{2}\) there, and \(f'(a) \gt 0\) for \(a \gt e^{-3/2}\), so \(f\) decreases and then increases.)
  4. Compute the minimum value. Use \(\ln e^{-3/2} = -\frac{3}{2}\). \[\begin{aligned} f\left(e^{-3/2}\right) &= 2e^{-3/2}\cdot\left(-\tfrac{3}{2}\right) + e^{-3/2}\\ &= -3e^{-3/2} + e^{-3/2}\\ &= -2e^{-3/2}. \end{aligned}\]

Answer: the minimum value is \(-2e^{-3/2} = -\dfrac{2}{e^{3/2}}\), reached at \(a = e^{-3/2}\).

Problem 7
Slaman, Fall 2010, Final Differentiate each function.
(a) \(f(x) = x^x\) for \(x \gt 0\)
(b) \(g(x) = \left(2\ln(x + 2) + 1\right)^{200}\)
Show full solution
  1. (a) The variable is in both the base and the exponent, so neither the power rule (which needs a constant exponent) nor the rule for \(a^x\) (which needs a constant base) applies. Use logarithmic differentiation: set \(y = x^x\) and take the natural log of both sides. This is allowed because \(x^x \gt 0\) for \(x \gt 0\). \[\ln y = \ln x^x = x\ln x.\]
  2. Differentiate both sides with respect to \(x\). The left side needs the chain rule, giving \(\frac{1}{y}\frac{dy}{dx}\). The right side is a product, so use the product rule with \(u = x\), \(v = \ln x\), \(u' = 1\), \(v' = \frac{1}{x}\). \[\begin{aligned} \frac{1}{y}\frac{dy}{dx} &= 1\cdot\ln x + x\cdot\frac{1}{x}\\ &= \ln x + 1. \end{aligned}\]
  3. Multiply both sides by \(y\) and replace \(y\) with \(x^x\). \[\frac{dy}{dx} = y(\ln x + 1) = x^x(\ln x + 1).\]
  4. (b) This is a function raised to the constant power \(200\), so use the generalized power rule \(\frac{d}{dx}[h(x)]^n = n[h(x)]^{n - 1}h'(x)\) with \(h(x) = 2\ln(x + 2) + 1\). First find \(h'(x)\). By the chain rule \(\frac{d}{dx}\ln(x + 2) = \frac{1}{x + 2}\cdot 1\), and the constant \(1\) has derivative \(0\). \[h'(x) = 2\cdot\frac{1}{x + 2} + 0 = \frac{2}{x + 2}.\]
  5. Put the pieces into the generalized power rule and simplify the constants. \[\begin{aligned} g'(x) &= 200\left(2\ln(x + 2) + 1\right)^{199}\cdot\frac{2}{x + 2}\\ &= \frac{400\left(2\ln(x + 2) + 1\right)^{199}}{x + 2}. \end{aligned}\]

Answer: (a) \(f'(x) = x^x(\ln x + 1)\). (b) \(g'(x) = \dfrac{400\left(2\ln(x + 2) + 1\right)^{199}}{x + 2}\).

Problem 8
Woodin, Fall 2012, Midterm 2 The curve \(x^4 + y^4 = 8xy\) passes through the point \((2, 2)\). Find the equation of the tangent line to the curve at that point.
Show full solution
  1. Check that the point is on the curve. At \((2, 2)\) the left side is \(2^4 + 2^4 = 16 + 16 = 32\) and the right side is \(8\cdot 2\cdot 2 = 32\). They match.
  2. Differentiate both sides with respect to \(x\), treating \(y\) as a function of \(x\). On the left, the chain rule gives \(\frac{d}{dx}y^4 = 4y^3\frac{dy}{dx}\). On the right, \(8xy\) is a product, so use the product rule with \(u = 8x\), \(v = y\), \(u' = 8\), \(v' = \frac{dy}{dx}\). \[4x^3 + 4y^3\frac{dy}{dx} = 8y + 8x\frac{dy}{dx}.\]
  3. Collect the terms with \(\frac{dy}{dx}\) on the left and everything else on the right, then factor out \(\frac{dy}{dx}\). \[\begin{aligned} 4y^3\frac{dy}{dx} - 8x\frac{dy}{dx} &= 8y - 4x^3\\ \left(4y^3 - 8x\right)\frac{dy}{dx} &= 8y - 4x^3\\ \frac{dy}{dx} &= \frac{8y - 4x^3}{4y^3 - 8x} = \frac{2y - x^3}{y^3 - 2x}. \end{aligned}\]
  4. Substitute \(x = 2\) and \(y = 2\) to get the slope. \[m = \frac{2\cdot 2 - 2^3}{2^3 - 2\cdot 2} = \frac{4 - 8}{8 - 4} = \frac{-4}{4} = -1.\]
  5. Write the tangent line in point-slope form and simplify. \[\begin{aligned} y - 2 &= -1(x - 2)\\ y &= -x + 2 + 2\\ y &= -x + 4. \end{aligned}\]

Answer: \(y = -x + 4\).

Problem 9
Paulin, Fall 2017, Midterm 2 Find and classify the relative extrema of \(f(x) = x^{2/3} - x^{5/3}\). Justify your answer carefully.
Show full solution
  1. Note the domain. Cube roots exist for every real number, so \(x^{2/3} = \left(\sqrt[3]{x}\right)^2\) and \(x^{5/3} = \left(\sqrt[3]{x}\right)^5\) are defined everywhere. The domain is all real numbers.
  2. Differentiate with the power rule. \[f'(x) = \frac{2}{3}x^{-1/3} - \frac{5}{3}x^{2/3}.\]
  3. Factor so the sign is easy to read. Pull out \(\frac{1}{3}x^{-1/3}\), using \(x^{2/3} = x^{-1/3}\cdot x\). \[\begin{aligned} f'(x) &= \frac{1}{3}x^{-1/3}(2 - 5x)\\ &= \frac{2 - 5x}{3x^{1/3}}. \end{aligned}\]
  4. Find the critical numbers. \(f'(x) = 0\) when the numerator is zero: \(2 - 5x = 0\), so \(x = \frac{2}{5}\). \(f'(x)\) does not exist when the denominator is zero: \(3x^{1/3} = 0\), so \(x = 0\). Since \(f(0) = 0\) is defined, \(x = 0\) is a critical number too. The critical numbers are \(0\) and \(\frac{2}{5}\).
  5. Make a sign chart for \(f'\) with one test value in each interval. Use \(x = -1\), \(x = \frac{1}{8}\) (because \(\sqrt[3]{1/8} = \frac{1}{2}\)), and \(x = 1\). \[\begin{aligned} f'(-1) &= \frac{2 - 5(-1)}{3(-1)} = \frac{7}{-3} \lt 0,\\ f'\left(\tfrac{1}{8}\right) &= \frac{2 - \frac{5}{8}}{3\cdot\frac{1}{2}} = \frac{\frac{11}{8}}{\frac{3}{2}} = \frac{11}{12} \gt 0,\\ f'(1) &= \frac{2 - 5}{3\cdot 1} = -1 \lt 0. \end{aligned}\]
    Interval\((-\infty, 0)\)\(\left(0, \frac{2}{5}\right)\)\(\left(\frac{2}{5}, \infty\right)\)
    Sign of \(f'\)\(-\)\(+\)\(-\)
    \(f\) isdecreasingincreasingdecreasing
  6. Classify with the first derivative test. Because \(f\) is continuous at \(0\) and \(f'\) changes from negative to positive there, \(f\) has a relative minimum at \(x = 0\). Because \(f'\) changes from positive to negative at \(x = \frac{2}{5}\), \(f\) has a relative maximum there.
  7. Find the \(y\)-values. At \(0\), \(f(0) = 0 - 0 = 0\). At \(\frac{2}{5}\), factor out \(\left(\frac{2}{5}\right)^{2/3}\), using \(\left(\frac{2}{5}\right)^{5/3} = \left(\frac{2}{5}\right)^{2/3}\cdot\frac{2}{5}\). \[\begin{aligned} f\left(\tfrac{2}{5}\right) &= \left(\tfrac{2}{5}\right)^{2/3} - \left(\tfrac{2}{5}\right)^{2/3}\cdot\tfrac{2}{5}\\ &= \left(\tfrac{2}{5}\right)^{2/3}\left(1 - \tfrac{2}{5}\right)\\ &= \tfrac{3}{5}\left(\tfrac{2}{5}\right)^{2/3}. \end{aligned}\] This is about \(0.33\). The graph has a sharp point (a cusp) at the origin because \(f'\) is undefined there.

Answer: relative minimum at \((0, 0)\) and relative maximum at \(\left(\frac{2}{5}, \frac{3}{5}\left(\frac{2}{5}\right)^{2/3}\right)\).

Problem 10
Paulin, Fall 2017, Midterm 2 Find the intervals on which \(f(x) = 4x^{1/3} - x^{4/3}\) is concave up and the intervals on which it is concave down. Does the graph have any inflection points? Justify your answer carefully.
Show full solution
  1. Note the domain. Cube roots exist for all real numbers, so the domain is all real numbers and \(f\) is continuous everywhere.
  2. Differentiate twice with the power rule. \[\begin{aligned} f'(x) &= \frac{4}{3}x^{-2/3} - \frac{4}{3}x^{1/3},\\ f''(x) &= -\frac{8}{9}x^{-5/3} - \frac{4}{9}x^{-2/3}. \end{aligned}\]
  3. Factor \(f''\) so its sign is easy to read. Pull out \(-\frac{4}{9}x^{-5/3}\), using \(x^{-2/3} = x^{-5/3}\cdot x\). \[\begin{aligned} f''(x) &= -\frac{4}{9}x^{-5/3}(2 + x)\\ &= -\frac{4(x + 2)}{9x^{5/3}}. \end{aligned}\]
  4. Find where \(f''\) is zero or undefined. The numerator is zero at \(x = -2\). The denominator is zero at \(x = 0\), where \(f''\) does not exist. These two numbers split the line into three intervals.
  5. Make a sign chart for \(f''\). Remember that \(x^{5/3} = \left(\sqrt[3]{x}\right)^5\) has the same sign as \(x\). \[\begin{aligned} f''(-3) &= -\frac{4(-1)}{9(-3)^{5/3}} = \frac{4}{(\text{negative})} \lt 0,\\ f''(-1) &= -\frac{4(1)}{9(-1)} = \frac{4}{9} \gt 0,\\ f''(1) &= -\frac{4(3)}{9(1)} = -\frac{4}{3} \lt 0. \end{aligned}\]
    Interval\((-\infty, -2)\)\((-2, 0)\)\((0, \infty)\)
    Sign of \(f''\)\(-\)\(+\)\(-\)
    \(f\) isconcave downconcave upconcave down
  6. Find the inflection points. Our course defines an inflection point as a point \((c, f(c))\) where \(f\) is continuous and the concavity changes. At \(x = -2\) the concavity changes from down to up, so there is an inflection point. Its \(y\)-value uses \((-2)^{1/3} = -\sqrt[3]{2}\) and \((-2)^{4/3} = \left(-\sqrt[3]{2}\right)^4 = 2\sqrt[3]{2}\). \[\begin{aligned} f(-2) &= 4\left(-\sqrt[3]{2}\right) - 2\sqrt[3]{2}\\ &= -4\sqrt[3]{2} - 2\sqrt[3]{2}\\ &= -6\sqrt[3]{2}. \end{aligned}\]
  7. At \(x = 0\) the function is continuous, \(f(0) = 0\), and the concavity changes from up to down, so \((0, 0)\) is also an inflection point under our course's definition. The graph has a vertical tangent line there. Paulin's posted solution lists only \(x = -2\). Its margin notes point out that \(f'(0)\) does not exist, which suggests his course also required the derivative to exist at an inflection point. On Prof. Gomez's exam, list both points and say why.

Answer: concave down on \((-\infty, -2)\) and \((0, \infty)\), concave up on \((-2, 0)\). Inflection points at \(\left(-2, -6\sqrt[3]{2}\right)\) and \((0, 0)\).

Problem 11
Demmel, Fall 2008, Midterm 2 Let \(f(x) = -x^3 + 3x^2 + 9x - 5\).

Problem 13
Woodin, Fall 2012, Midterm 2 problem list Let \(y = \left((\ln x)^2\right)^x\) for \(x \gt 0\). Find \(y'\left(\frac{1}{e}\right)\).
Show full solution
  1. The variable is in both the base \((\ln x)^2\) and the exponent \(x\), so use logarithmic differentiation. Near \(x = \frac{1}{e}\) the base is positive (it equals \(1\) at \(x = \frac{1}{e}\)), so we may take the natural log of both sides and use \(\ln A^k = k\ln A\). \[\ln y = \ln\left((\ln x)^2\right)^x = x\ln\left((\ln x)^2\right).\]
  2. Differentiate both sides with respect to \(x\). The left side gives \(\frac{1}{y}\frac{dy}{dx}\) by the chain rule. The right side is a product, so use the product rule with \(u = x\), \(v = \ln\left((\ln x)^2\right)\), \(u' = 1\), and \(v'\) found in the next step. \[\frac{1}{y}\frac{dy}{dx} = 1\cdot\ln\left((\ln x)^2\right) + x\cdot v'.\]
  3. Find \(v'\) with the chain rule twice. The derivative of \(\ln h\) is \(\frac{h'}{h}\) with \(h = (\ln x)^2\), and by the generalized power rule \(h' = 2\ln x\cdot\frac{1}{x}\). \[\begin{aligned} v' &= \frac{1}{(\ln x)^2}\cdot 2\ln x\cdot\frac{1}{x}\\ &= \frac{2}{x\ln x}. \end{aligned}\]
  4. Substitute \(v'\) back and simplify the second term, since \(x\cdot\frac{2}{x\ln x} = \frac{2}{\ln x}\). Then multiply by \(y\). \[\begin{aligned} \frac{1}{y}\frac{dy}{dx} &= \ln\left((\ln x)^2\right) + \frac{2}{\ln x},\\ \frac{dy}{dx} &= \left((\ln x)^2\right)^x\left[\ln\left((\ln x)^2\right) + \frac{2}{\ln x}\right]. \end{aligned}\]
  5. Evaluate at \(x = \frac{1}{e}\). There \(\ln\frac{1}{e} = -1\), so \((\ln x)^2 = 1\), \(\ln 1 = 0\), and \(y = 1^{1/e} = 1\). \[\begin{aligned} y'\left(\tfrac{1}{e}\right) &= 1\cdot\left[\ln 1 + \frac{2}{-1}\right]\\ &= 1\cdot[0 - 2]\\ &= -2. \end{aligned}\]

Answer: \(y'\left(\frac{1}{e}\right) = -2\).

Problem 14
Woodin, Fall 2012, Midterm 2 Let \(h(x) = -|x| + x^5\).
(a) Does \(h\) have any relative maximum or relative minimum points? If so, find and identify them.
(b) Does \(h\) have any inflection points? If so, find them.
Show full solution
  1. Write \(h\) without the absolute value. Since \(|x| = x\) for \(x \ge 0\) and \(|x| = -x\) for \(x \lt 0\), \[h(x) = \begin{cases} -x + x^5, & x \ge 0,\\ x + x^5, & x \lt 0. \end{cases}\] Both pieces give \(h(0) = 0\), and \(h\) is continuous everywhere because \(|x|\) and \(x^5\) are.

Differentiate each piece away from \(0\). \[h'(x) = \begin{cases} -1 + 5x^4, & x \gt 0,\\ 1 + 5x^4, & x \lt 0. \end{cases}\] As \(x\) approaches \(0\) from the right the slope approaches \(-1\), and from the left it approaches \(1\). The two one-sided slopes disagree, so the graph has a corner and \(h'(0)\) does not exist. Since \(h(0)\) is defined, \(x = 0\) is a critical number.

Call this number \(c = 5^{-1/4}\), about \(0.67\). The critical numbers are \(0\) and \(c\).

    Interval\((-\infty, 0)\)\((0, c)\)\((c, \infty)\)
    Sign of \(h'\)\(+\)\(-\)\(+\)
    \(h\) isincreasingdecreasingincreasing
  5. Classify with the first derivative test, which works at a corner as long as \(h\) is continuous there. At \(x = 0\), \(h'\) changes from positive to negative, so \((0, 0)\) is a relative maximum. At \(x = c\), \(h'\) changes from negative to positive, so there is a relative minimum. Its \(y\)-value uses \(c^4 = \frac{1}{5}\), so \(c^5 = c\cdot c^4 = \frac{c}{5}\). \[h(c) = -c + c^5 = -c + \frac{c}{5} = -\frac{4}{5}c = -\frac{4}{5}\cdot 5^{-1/4}.\]

Problem 15
Woodin, Fall 2012, Midterm 2 Let \(f(x) = e^x - \dfrac{x^3}{6} + x^2 + 3x + 4\).
(a) Let \(g(x) = f''(x)\). Find the minimum value of \(g(x)\).
(b) Does \(f\) have an inflection point? Explain.
Show full solution
  1. (a) Differentiate \(f\) twice, term by term. \[\begin{aligned} f'(x) &= e^x - \frac{3x^2}{6} + 2x + 3 = e^x - \frac{x^2}{2} + 2x + 3,\\ g(x) = f''(x) &= e^x - x + 2. \end{aligned}\]
  2. Find the critical numbers of \(g\). \[\begin{aligned} g'(x) &= e^x - 1 = 0\\ e^x &= 1\\ x &= 0. \end{aligned}\]
  3. Show that \(x = 0\) gives the absolute minimum of \(g\). For \(x \lt 0\), \(e^x \lt 1\), so \(g'(x) \lt 0\) and \(g\) is decreasing. For \(x \gt 0\), \(e^x \gt 1\), so \(g'(x) \gt 0\) and \(g\) is increasing. A function that decreases all the way up to \(x = 0\) and increases from then on has its smallest value at \(x = 0\). (The second derivative test agrees: \(g''(x) = e^x\), so \(g''(0) = 1 \gt 0\).)
  4. Compute the minimum value. \[g(0) = e^0 - 0 + 2 = 1 + 2 = 3.\]
  5. (b) An inflection point requires the concavity to change, which means \(f''\) has to change sign. By part (a), \(f''(x) = g(x) \ge 3\) for every \(x\), so \(f''(x) \gt 0\) everywhere. The graph of \(f\) is concave up on all of \((-\infty, \infty)\), the concavity never changes, and \(f\) has no inflection point.

Answer: (a) The minimum value of \(g(x) = f''(x) = e^x - x + 2\) is \(3\), at \(x = 0\). (b) No. \(f''(x) \ge 3 \gt 0\) for all \(x\), so \(f\) is concave up everywhere and its concavity never changes.

At \(x = 2\), \(f'\) changes from positive to negative, so there is a relative maximum, with \(f(2) = -2 + \frac{1}{1 - 2} = -2 - 1 = -3\).   5. Classify. Because \(f'\) changes from negative to positive at \(x = \frac{1}{2}\), \(f\) has a relative minimum there. Its value is \[f\left(\tfrac{1}{2}\right) = \frac{e^{2\cdot\frac{1}{2}}}{\frac{1}{2}} = \frac{e}{\frac{1}{2}} = 2e.\] This is the only relative extremum.
  6. Decide whether \(2e\) is an absolute minimum. It is not, because the function takes smaller values for negative \(x\). For example \[f(-1) = \frac{e^{-2}}{-1} = -e^{-2} \lt 0 \lt 2e.\] In fact there is no absolute minimum at all: as \(x \to 0^-\), the numerator approaches \(1\) and the denominator is a small negative number, so \(f(x) \to -\infty\).
  7. There is also no absolute maximum: as \(x \to 0^+\), the numerator approaches \(1\) and the denominator is a small positive number, so \(f(x) \to \infty\).

Answer: the only relative extremum is a relative minimum at \(\left(\frac{1}{2}, 2e\right)\). It is not an absolute minimum, since \(f(-1) = -e^{-2} \lt 2e\) (and \(f(x) \to -\infty\) as \(x \to 0^-\)). The function has no absolute extrema.
